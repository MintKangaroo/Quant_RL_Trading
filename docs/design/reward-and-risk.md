# 보상 함수와 리스크 예산

## 1. 목표의 수식화

> 시장보다 덜 잃고, 시장보다 더 번다.

대표 지표는 **정보비율(IR) = 연 초과수익 ÷ 트래킹에러**.
수익률 하나만 보면 리스크를 얼마나 태웠는지가 숨는다.

---

## 2. 보상 함수

```
r_t = (r_port,t − r_bench,t) − w(d_t)·Δd_t − cost_t
```

| 항 | 의미 |
|---|---|
| `r_port` | 포트폴리오 일간 수익률 (**원화 기준**) |
| `r_bench` | 혼합 벤치마크 일간 수익률 |
| `Δd_t` | 이번 스텝에 **새로 깊어진** 낙폭. 신저점 갱신 시에만 > 0 |
| `w(d)` | 현재 낙폭 깊이별 한계 페널티 가중치 |
| `cost_t` | 수수료·거래세·슬리피지·환전 실비 |

### 낙폭 페널티 `w(d)`

```
d < 12%         →  w = 0      자유구간
12% ≤ d < 22%   →  w = 1.5
22% ≤ d < 30%   →  w = 8.0
d ≥ 30%         →  에피소드 종료 + 큰 음수
```

읽는 법: **22%를 넘으면 낙폭 1%p가 초과수익 8%p만큼 아프다.**

**자유구간 12%가 이 펀드의 투자철학이다.**
선형 페널티(`− λ·MDD`)를 쓰면 에이전트가 *모든* 낙폭을 피하려 들어 방어에 집착하고,
결과적으로 "덜 잃고 덜 버는" 정책으로 수렴한다. 작은 낙폭은 비용이 아니라 정상 영업이다.

### 조밀 보상인 이유

MDD를 에피소드 끝에 한 번 정산하면 희소 보상이 되어 크레딧 할당이 실패한다.
`Δd` 방식은 **신저점을 찍는 순간** 벌점을 주므로 가치함수가 학습할 신호가 생긴다.

### 에피소드 길이

**최소 250거래일.** MDD는 경로 통계라서 에피소드가 짧으면 낙폭을 만들 시간 자체가 없고,
30% 벽이 죽은 항이 된다.

과거 데이터가 5년(약 1,250거래일)이므로 겹치지 않는 에피소드는 5개뿐이다.
반드시 **겹치는 윈도우 + 다중 시드 + 종목 부트스트랩**으로 표본을 늘리고,
**purged K-fold + embargo 5일**로 누수를 막는다.

## 3. 벤치마크

```
혼합 벤치마크 = 0.5 × KOSPI + 0.5 × S&P500(원화 환산)
```

**비중은 고정한다.** Allocator가 KR/US 배분을 정하는데 벤치마크도 그 비중을 따라가면
RL이 자기 시험 문제를 자기가 내는 셈이 된다.

성과는 **원화 기준**으로 평가한다. 원화는 위기에 약해지는 통화라
하락장에서 원달러 상승이 미장 손실을 상쇄한다 — 즉 **미장 포지션이 자연 헤지**로 작동한다.
Allocator가 이를 학습하려면 상태값에 **환율·환율변동성·한미 금리차**가 반드시 포함되어야 한다.

## 4. 3층 임계치

같은 30%를 세 곳에 다르게 적용한다.

| 층 | 값 | 성격 |
|---|---|---|
| 학습 보상 자유구간 | 12% | soft |
| 승격 게이트 상한 | 20% | OOS 백테스트 기준 |
| 실운영 재난 킬스위치 | 30% | hard latch |

게이트를 30%가 아닌 20%로 잡는 이유: 백테스트 MDD는 실전에서 거의 항상 더 나쁘다
(슬리피지, 유동성 고갈, 미관측 레짐). 20%로 통과시켜야 실전이 30% 안에 머문다.

## 5. 비용 모델

**튜닝 대상이 아니라 실비다.** 시뮬레이터 안에서 직접 차감한다.

```
충격비용 = k × 변동성 × √(주문량 / 일평균거래량)
```

- 국장 왕복 약 0.2~0.35% (수수료 + 거래세 + 슬리피지)
- 미장 슬리피지 + 거래대금 기준 수수료
- 환전 스프레드는 실제 우대율을 확인해 반영

**제약**
- 매수 상한: 일 거래대금의 3%
- 청산 제약: 평시 거래량 기준 **3일 안에 전량 청산 가능한 수준**을 넘으면 신규매수 차단
  (위기 시 유동성은 절반 이하로 마르므로 3일은 실제로 6일이 된다)

## 6. KR/US 배분과 환전 데드밴드

- 배분 변경은 **주 1회** (금요일 마감 후). 일간 액션에 넣으면 매일 환전하며 자본이 녹는다
- 목표와 현재 배분 차이가 **10%p를 넘을 때만** 환전
- 그 아래는 환전 없이 각 시장 안에서만 조정

## 7. 자본 단계

초기 자본은 소액이다. 이 구간의 성격을 오해하면 안 된다.

| | 검증 대상 |
|---|---|
| 백테스트 / shadow | **전략이 돈을 버는가** |
| 실전 소액 구간 | **시스템이 설계대로 도는가** |

소액 구간의 수익률로 전략을 판단하지 않는다. 보유 종목이 적어 운의 분산이 지배한다.

### 소액 구간에서 실제로 무너지는 것

- 3% 거래대금 상한이 걸리지 않는다 → **자본 규모별로 백테스트를 따로 돌려야 한다**
- 정수 라운딩으로 목표 비중(4.2%)이 실제로는 0% 또는 12%가 된다
- 환전 왕복 비용이 수익을 압도한다

### 대응

- 상태값에 `log(자본규모)` 와 종목별 **최소 스텝**(1주 = 몇 %)을 넣는다.
  이게 있으면 소액에서 학습한 정책이 자본이 커져도 무너지지 않는다
- Executor는 살 수 없는 고가주를 후보에서 사전 제외한다
- 목표 비중과 실현 비중의 괴리를 대시보드에 표시한다

### 증액 게이트

수익률이 아니라 **시스템 무결성**으로 판정한다.

| 항목 | 기준 |
|---|---|
| 무중단 운영 | 60거래일 |
| 슬리피지 정확도 | 실측이 모델 예측의 ±30% 이내 |
| 주문 실패율 | 1% 미만 |
| 데이터 결측률 | 0.5% 미만 |
| 킬스위치 | 실제 발동 테스트 통과 |
| shadow–실전 괴리 | 같은 신호의 수익률 차이가 허용범위 |
| shadow IR | 양수 유지 |

증액 폭은 한 단계에 2~3배. 매 단계마다 위 게이트를 재통과하고,
**"이 금액의 30%를 정말 견딜 수 있는가"** 를 사람이 다시 답한다.

## 8. 선택과 노출의 성적표를 가른다 (2026-08-25 — 1회차 실측이 근거다)

### 무엇이 문제였나

§2 의 보상 `(r_port − r_bench)` 는 서로 다른 두 결정을 한 숫자에 섞는다:

    무엇을 샀나 (종목 선택)   +   얼마나 샀나 (노출·현금)

24종목을 다 잘 골라도 주식을 들고 있던 날 시장이 빠지면 벌점이다. 종목
선택의 잘잘못이 노출 결정의 결과에 파묻힌다 — **섞인 성적표로는 어느 과목을
잘했는지 배울 수 없다.**

1회차(2026-08-25)가 이것을 실측으로 보여줬다:

    advantage ↔ 종목선택 정렬도 상관   r ≈ 0.043      ← 선택 신호는 극도로 흐릿
    비용·낙폭 페널티                   행동에 결정적    ← 벌점은 또렷
    → 96,000 그래디언트 스텝 동안 보상 -0.017 에서 정체
    → 정책이 배운 것: 현금 6.5% → 13.8% ("덜 풀면 감점이 없다")

정책은 멍청해서 도망간 것이 아니다. **우리가 만든 시험에서 도망이 실제로
합리적이었다.**

### 바꾸는 것 — 선택 항의 기준을 후보 균등가중으로

    r_t = (r_port,t − r_eq,t)  +  (r_eq,t − r_bench,t)  − w(d_t)·Δd_t − cost_t
          └── 선택 점수 ──┘      └── 노출 점수 ──┘

    r_eq = **그날 같은 후보를 균등가중으로 샀을 때**의 수익률 (현금 비중은
           정책의 것을 그대로 둔다 — 노출 결정을 선택 점수에 안 섞기 위해)

수학적으로 두 항의 합은 기존 `(r_port − r_bench)` 와 같다 — **총보상은 안
바뀐다.** 바뀌는 것은 **각 머리에 흘리는 그래디언트**다: 비중 머리는 선택
점수로만, 현금·노출 축은 노출 점수로만 배운다.

### 왜 이러면 신호가 커지나

같은 후보끼리 견주면 시장·후보 공통의 출렁임이 통째로 빠진다(분산 축소
제어변수다). 남는 것은 "비중을 더 준 종목이 덜 준 종목보다 나았나" —
정확히 비중 머리가 배워야 할 것뿐이다. 노이즈가 줄면 같은 데이터에서
r 이 오르고, 필요 학습량은 r² 에 반비례해 준다.

### 지키는 것

- 낙폭 페널티·비용 항은 **그대로다** (§2 의 철학 유지). 다만 커리큘럼
  C1(비용 0)부터 다시 시작한다 — rl-training.md §6 이 원래 그렇게 시켰는데
  1회차가 건너뛰었다.
- `r_eq` 는 그날 후보와 정책의 현금 비중에서 계산되므로 **미래를 안 본다.**
- LLM 출력은 여전히 보상에 없다 (CLAUDE.md 불변식 8).

### 검증 (구현 뒤)

1. 두 항의 합 = 기존 보상 (기계 정밀도) — 회귀 아님을 증명
2. 오라클 카나리에서 **선택 점수의 advantage↔정렬도 r** 이 기존 방식보다
   커지는지 — 이 설계의 존재 이유이므로, 안 커지면 되돌린다
3. 균등가중 대비 우위(evaluate_policy)가 판정 기준인 것은 그대로
