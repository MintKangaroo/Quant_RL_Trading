# AI 아키텍처 v2 — 지수 코어 위에 세 층의 알파 (2026-09-25)

사용자 지시(2026-09-25): "AI 설계 다시 한번 — 지도·비지도·강화학습으로 전반적인 매매, 정교하게. 가능성이 조금이라도 보이면 학습 돌려보고
실전 투입까지" · "지수를 사도 돼, 대신 지수를 이기고 알파를 내면 돼" · 경로 분석의 두 결론(RL 환경을 실전과 맞춘다, RL 은 노출·재조정에) "응 바꿔".

근거 조사 셋(서브에이전트, 2026-09-25): 데이터 전수 조사 · 실패 원인 종합(rl-postmortem·trials-postmortem·프로토콜 결과 절 전부) ·
매매 경로의 학습 부착점 지도(session/daily.py 기준). 이 문서의 숫자는 거기서 왔다.

## 0. 한 문단 요약

**지수를 코어로 들고, 세 층의 학습이 그 위에 알파를 얹는다.** 지도학습 랭커(이미 챔피언)는 "어느 종목을 더·덜" — 상위 24 에 몰아 쓰지 않고
지수 비중 전체를 기울이는 데 쓴다. 비지도학습은 "지금 시장이 어떤 상태이고 종목이 어떻게 묶이나" — 국면 확률과 종목 군집을 만들어 두 층에
상태로 준다. 강화학습은 "얼마나 들고, 언제 다시 맞추나" — 행동이 스칼라 하나(노출)와 이진 하나(재조정)라 표본이 적어도 배울 수 있는 자리다.
배분(종목별 비중)을 RL 로 배우는 것은 네 번 천장을 확인했으므로 하지 않는다. 판정은 전부 **지수(KODEX200 / SPY) 대비 비용 후 IR** 이다.
"≈지수" 는 실패다.

## 1. 왜 이렇게 — 증거

| 사실 | 수치 | 설계에 주는 뜻 |
|---|---|---|
| 학습이 이긴 곳은 하나 | 랭커 목적을 rank-gauss 로(시행 L) ΔIC KR +0.028(t 2.88)·US +0.031(t 4.40). 주간 IC KR 0.099·US 0.063, 감쇠 없음 | 지도학습 랭커는 유지 — 바꿀 것은 **쓰는 방식** |
| 같은 재료의 천장이 낮다 | 기존 6신호를 사후 최적 재가중해도 20일 185bp. 완벽 선정과 격차 3,871bp | 용량(더 큰 모델)으로는 못 번다 — 새 정보·구조 |
| 이긴 개선은 전부 "쓰는 방식" | 평활·완충 t 3.55 · C10 +6.2%p · AT +6.0%p · Z2 +12.8%p | 신호를 폭넓게·덜 자주 쓴다 |
| 상위 24 는 칼날 | 하루 유지율 66% · 시드 잡음 연 3.7%p · 같은 IC 두 모델이 연 11%p 갈림 | 신호를 한 점(24)에 모으지 않는다 → **지수 전체를 기울인다** |
| 배분 RL 은 천장 | 반영률 0.95 로 운전대를 잡고도 균등가중 대비 0(3·4회차), 5회차 −41%p | 종목 비중 RL 금지 |
| RL 환경이 실전과 달랐다 | 학습 env 에 완충(held)·C10·노출·분할 없음(allocator/cache.py:234, env) | 새 RL env 는 **실전 경로 그대로** |
| 거래의 76%가 노출 | 수익 분해 노출 항 −3.03~−4.47%p · V6 +3.4%p 였지만 전환 비용 | 노출이 RL 의 1순위 자리 |
| 지수가 이기는 이유 | 초대형주 몇 개(삼성·하이닉스 / NVDA·AAPL)가 지수를 끈다 | 코어는 지수, 알파는 그 위에 |

**정보비율 ≈ IC × √폭 × 전달률.** 지금은 폭(24)과 전달률(동일가중 ↔ 지수 어긋남)을 스스로 깎는다. v2 는 이 두 항을 되돌린다.

## 2. 구조

```
            ┌──────────────────────────── 판정: 지수 대비 비용 후 IR (KODEX200 · SPY) ────────────────────────────┐
 데이터 ──▶ │ [비지도 U] 국면 확률 p(regime) · 종목 군집 c(i)                                                    │
            │        │                         │                                                             │
            │        ▼                         ▼                                                             │
            │ [지도 S] 랭커 점수 z(i) ──▶ [코어+기울이기] w(i) = 지수비중(i) × exp(λ·z̃(i)) (군집 중립·상한)       │
            │                                   │                                                           │
            │                                   ▼                                                           │
            │ [강화 R] 노출 k ∈ [0.3, 1] · 재조정 여부 b ∈ {0,1}  ← 상태: p(regime), 낙폭, 점수 변화, 회전 압력 │
            │                                   │                                                           │
            │                                   ▼                                                           │
            │ [집행 — AI 없음] 가드 → 수량 → 분할 → 전송 → 실현 비중 되먹임(불변식 6·7)                       │
            └───────────────────────────────────────────────────────────────────────────────────────────────┘
```

### L0 — 코어: 지수 비중

- 국장: K200 유동시총(시가총액 × 유동비율, 종목 상한 30%). 미장: 시총 상위 500(증권 종류 필터, 같은 회사 클래스 하나, 상한 10%).
- 코드: `allocator/float_cap_baseline.py`(있음) + `selector/filters.py` 의 `index_members`·`top_market_cap_rank`(있음).

### L1 — 지도학습: 어느 종목을 더·덜 (챔피언 유지, 쓰는 방식만 바꾼다)

- **점수**: 기존 랭커(`analysts/ranker.py`, rank-gauss GBM). 입력 추가는 새 정보원이 관문을 넘을 때만(내부자 AR·잠정실적 G8·컨센서스 — §6).
- **쓰는 방식**: 상위 24 동일가중 → **지수 비중 × exp(λ·z̃)** (인핸스드 인덱스). z̃ 는 코어 안 점수의 rank-gauss, **군집 중립**(L2 의 c(i) 안에서
  평균을 빼) — 기울이기가 한 업종에 쏠려 벤치와 어긋나는 것을 막는다(전달률).
- 시행: **AZ(국장)·AX(미장) — 9/26~27 측정 중**. 군집 중립 변형은 AZ/AX 통과 뒤 별도 등록(아래 로드맵 S2).
- 재학습: 11월 금고 개봉 뒤 월 1회(modelops-ranker.md ③) — 그 전엔 2026-06-30 열.

### L2 — 비지도학습: 지금 어떤 상태이고, 종목이 어떻게 묶이나

- **U1 국면 확률**: 규칙 `regime.classify`(20일 수익·60일 변동성 분위) 대신 **가우시안 HMM(3~4 상태)** 을 지수의 [수익, 실현변동성, 시장 폭(상승 종목 비율),
  신용 스프레드 대용(미장 금리차)]에 적합 → 상태 확률 p(regime). 확장창 워크포워드로 적합(미래 안 봄), 상태 이름은 평균 수익·변동성 순위로 고정.
  쓰임: L3 의 상태값(확률 벡터 — 계단식 국면보다 연속이라 전환 비용이 준다). 규칙 국면과 **같은 판정**(노출 오버레이 수익·MDD)으로 비교.
- **U2 종목 군집**: 60일 수익 상관(또는 잔차 상관)의 계층 군집 → c(i). 쓰임: L1 기울이기 중립화, 리스크 패리티의 섹터 대체(`selector/ksic.py` 자리).
  KSIC 섹터는 분류를 모르는 종목이 많고 미장엔 없다(G1 첫 세션 "업종 분류 있는 종목 없음").
- 데이터: prices·indices(2021-08~) — 충분. 새 정보가 아니라 **표현**이다; 판정은 그것을 쓰는 층의 성과로만.

### L3 — 강화학습: 얼마나 들고, 언제 다시 맞추나

- **행동**: 노출 k ∈ [0.30, 1.0](연속, 0.05 단위로 양자화) + 재조정 b ∈ {0,1}(오늘 L1 목표로 다시 맞출지). 종목 비중은 **건드리지 않는다**(L0·L1 이 정한다).
- **상태**(전부 과거 이력이 있는 것 — CLAUDE.md): U1 p(regime) · 지수 20/60일 수익·변동성 · 낙폭 · 직전 노출 · 마지막 재조정 뒤 경과 세션 ·
  **국장: 전날 밤 미장(반도체지수 SOX·나스닥 수익, VIX 변화, 원/달러) — 미장 종가는 국장 개장 전에 확정된다(2026-09-25 사용자 승인 재료 ②)** ·
  목표 대비 현재 비중 괴리(½Σ|w*−w|, 재조정 압력) · 랭커 점수의 하루 변화 크기 · 실현 비중(불변식 7 — `accounting_fill_v2`).
- **보상**: r = (r_port,net − r_bench) − α·Δ낙폭 − 비용(회전 × 편도 비용). **포트폴리오 수준 시뮬레이터**로 학습 — 종목 수익·L1 목표 비중·
  노출·재조정·비용을 매일 굴린다(집행은 비용 모형; 분할·추격 없음 — 노출·재조정의 결정에는 충분하다).
- **표본 전략**: 행동 차원이 2라 표본이 적어도 된다. 그래도 에피소드를 늘리려고 **블록 부트스트랩**(20세션 블록 재배열)과 **3시드**.
  먼저 **맥락적 밴딧(LinUCB/Thompson)** 기준선 → 그다음 PPO. 밴딧이 이기지 못하면 PPO 는 안 한다.
- **환경 정합(경로 분석 결론)**: 시뮬레이터는 실전과 같은 규칙을 순수 함수로 공유한다 — `selector/cadence.py` 보유일 규칙, `exposure.apply`,
  완충(`pick_mult`/`exit_rank`), 비용 = config. 옛 `LatticeEnv` 는 쓰지 않는다(held·cadence·노출이 없다).
- **실전 경로**: 정책은 **세션 전에** 행동(k, b)을 내 창고에 적고, `session/daily.run` 은 그 값을 노출 배수·재조정일로 **읽기만** 한다(불변식 6 —
  Executor 는 순수). 반영률 = 1 − |k_target − k_realized| 등으로 잰다(30% 미만 경고).
- **왜 이 자리**: 거래의 76%가 노출이다 · 규칙 V6 는 계단식이라 전환이 비싸고 늦었다(AI: 회복을 146세션 늦게 알았다) · 행동이 작아 반영률이 높게 나온다.

### L4 — 집행(나중): Executor 밖의 조회표

룰 TWAP 1차 관문(~10/1) 뒤. 학습 결과는 **세션 전에 계산한 종목별 분할·지정가 오프셋 조회표**로만 Executor 에 들어간다(불변식 6). 분봉이 국장 ~100종목·
2개월뿐이라 지금은 표본이 모자란다 — 트리거(`drl-when-information-sufficient` ②) 전엔 안 연다.

## 5. 하지 않는 것

- 종목 비중 RL(배분) — 천장 확인(4회). 상위 N 규칙 미세조정 — 칼날 분산이 신호보다 크다.
- 더 큰 모델(RNN·트랜스포머·깊은 스택) — 같은 재료에서 전부 졌다. 독립 블록 57(국장)·42(미장).
- LLM 을 보상·상태에 — 불변식 8. 롱숏 — 국장 공매도 자료·제도 막힘.
