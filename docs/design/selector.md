# Selector — Analyst 가중치 진화

Analyst 점수를 어떻게 합칠 것인가. **여기가 알파의 결합부다.**
RL이 실패해도 이 층이 작동하면 시스템은 돈을 번다 (M3 룰 베이스라인이 곧 이것이다).

---

## 1. 합성 공식

```
combined(entity) = Σ(wᵢ · scoreᵢ · confᵢ) / Σ(wᵢ · confᵢ)
```

`wᵢ` 는 Analyst i 의 가중치. 이것을 진화로 탐색한다.

**처음부터 비선형 결합을 시도하지 않는다.** 신뢰도 가중합으로 시작해서
이것을 이기는 비선형이 나올 때만 교체한다. 복잡하게 시작하면 뭐가 문제인지 못 찾는다.

---

## 2. 유전자

```
w[9]                Analyst별 가중치, ≥ 0, 합 1로 정규화
corr_threshold      상관 페널티 임계 (0.5 ~ 0.9)
corr_penalty        감점 강도 (0 ~ 1)
n_candidates        후보 수 (15 ~ 30)
sector_cap          단일 섹터 비중 상한 (0.2 ~ 0.5)
```

**IC 0.03 을 통과하지 못한 Analyst 는 유전자에서 제외하고 `w = 0` 으로 고정한다.**
관찰 모드 Analyst가 진화에 참여하면 노이즈를 최적화하게 된다.

국장/미장은 **별도 개체군**으로 진화시킨다. Flow Analyst의 데이터 가용성이 아예 다르다.

---

## 3. 적합도

```
fitness = IR(검증 구간) − λ_L1 · Σ|wᵢ| − λ_turn · 회전율
```

- **IR** 로 평가한다. 수익률로 하면 리스크를 태운 개체가 이긴다
- **L1 페널티**가 핵심이다. 쓸모없는 Analyst의 가중치를 자동으로 0으로 밀어
  희소한 해를 만든다. 어떤 Analyst가 진짜 기여하는지가 결과로 드러난다
- 평가는 실제 백테스트로 한다 (비용·라운딩 포함). 점수 상관만으로 평가하면
  실제로 못 사는 종목으로 적합도를 얻는다

---

## 4. 알고리즘

```yaml
population: 64
generations: 40
selection: tournament (k=3)
crossover: SBX (eta=15), rate 0.9
mutation: gaussian (sigma=0.05), rate 0.2
elitism: 2
```

### 과적합 방지 — 이것이 진화의 최대 위험

64×40 = 2,560회 백테스트를 돌려 가장 좋은 것을 고르는 일이다.
**아무 신호가 없어도 좋아 보이는 개체가 반드시 나온다.**

| 장치 | 내용 |
|---|---|
| 폴드 리샘플링 | 매 세대 검증 구간을 다른 폴드로 교체. 한 구간에 맞춰지지 못하게 |
| 다중 시작일 | 개체당 여러 시작일 백테스트의 **중앙값**으로 평가 |
| L1 페널티 | 가중치 희소화 |
| walk-forward | 최종 검증은 별도 테스트 폴드에서 딱 한 번 |
| 조기 종료 | 검증 적합도가 10세대 개선 없으면 중단 |

### 안정성 검사 (필수)

**상위 10개 개체의 가중치가 서로 비슷한지 확인한다.**

- 비슷하다 → 적합도 지형에 실제 봉우리가 있다. 신뢰할 수 있다
- 제각각이다 → 지형이 평평하다. **진화 결과는 노이즈다.**
  이 경우 동일가중을 쓰는 것이 낫다

이 검사를 통과하지 못한 가중치는 채택하지 않는다.

## 5. 후보 선정 순서

```
1. 유니버스 필터
   거래대금 하한 / 관리종목·거래정지 제외 / 상장 6개월 경과
   1주 가격 < 자본의 15%

2. combined score 계산 (죽은 Analyst는 중립 0 처리)

3. News·SNS 거부 종목 제외 (거부 상한: 후보의 30%)

4. 상관 페널티
   이미 뽑힌 종목과 60일 상관 > corr_threshold 이면 corr_penalty 만큼 감점

5. 섹터 상한 적용

6. 상위 n_candidates 개 → 후보 리스트
```

3번을 4번보다 먼저 둔다. 상관 계산은 비싸고, 거부될 종목까지 계산할 이유가 없다.

---

## 6. 재진화 주기

- 분기 1회 정기
- 또는 어느 Analyst의 60일 IC 이동평균이 0.01 아래로 떨어질 때 (알파 소멸)
- 새 Analyst가 IC 0.03 을 통과해 합류할 때

**가중치 변경은 shadow 5거래일을 거친 뒤 반영한다.** 즉시 교체하지 않는다.
가중치 이력은 전부 저장해 언제 무엇이 바뀌었는지 추적 가능하게 한다.
