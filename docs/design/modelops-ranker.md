# ModelOps — 랭커 감시·재학습 (M5 남은 항목의 재정의, 2026-09-07)

M5 완료 기준 넷 중 남은 하나는 "Analyst 별 성과 귀속이 **가중치 진화**에 피드백" 이었다. 그 항목은 Analyst 점수를
가중합으로 섞던 때의 것이다. 2026-09-03 시행 L 로 랭커가 알파를 독점한 뒤(analyst_weights: ranker 1.0, 나머지 0)
가중치를 진화시킬 대상이 없다. 귀속이 피드백할 곳은 **가중치가 아니라 랭커의 유지보수 결정**이다 — 입력이 죽었는가,
모델이 낡았는가, 다시 학습할 때인가. self-improvement.md §2 의 L0(알파 감쇠 감지 → 재학습)·L1 이 여기 해당한다.

## 지금 상태 (사실)

- 랭커 모델 열: `ranker-v0.1.0-{20250630…20260630}`, 실전은 `usable_from ≤ as_of` 인 최신 열 = **2026-06-30 학습분**.
  홀드아웃(2026-07-01~)이 닫혀 있어 **11월 개봉 전엔 그 뒤 데이터로 학습할 수 없다.** 재학습은 그때까지 없다.
- IC 측정(`tools/measure_ic.py --save`)은 **사람이 돌린다.** 랭커 IC 이력은 5점(마지막 2026-09-03). 크론이 없다.
- 가중치 규칙(한계기여, `ic.marginal_shares`)은 `--save` 때만 갱신된다. 측정을 안 하면 가중치도 안 움직인다.

## 세 가지 — 순서대로

### ① 감시 (L0-a) — 주 1회 IC 측정과 경보

- 크론 **토 12:00** (아무 학습·백필도 안 도는 시간, memory `training-shares-no-machine`): `measure_ic --market KR --save`,
  이어서 `--market US --save`. 전 Analyst 를 잰다(랭커 입력의 IC 도 같은 명령이 낸다).
- 학습 탭 경보(임계치는 config, 불변식 10):
  - `analysts.ic_threshold`(0.03) 아래로 랭커 60세션 IC 가 **두 번 연속** 떨어지면 "랭커 감쇠" 경보. 한 번은 잡음이다.
    `modelops.ranker.fail_streak: 2` 신설.
  - 랭커 입력 여섯(chart·event·flow·fundamental·regime·risk) 중 IC 가 직전 측정 대비 절반 아래로 떨어진 것은 "입력 감쇠" 로
    이름을 적는다. 사이드카의 피처 gain 을 옆에 놓아 "그 입력이 모델에 얼마나 실려 있었나" 를 같이 보인다.
- **자동으로 바꾸지 않는 것**: 가중치는 한계기여 규칙이 정한다(지금도 그렇다). 랭커가 임계치 아래면 규칙이 가중치 0 을
  주고 fundamental 로 되돌아간다 — 그 전환 자체가 경보다. 사람이 끄지 않는다.
- 시행 예산: 주 1회 `--save` 는 research_trials `ic-analyst` 에 남는다(자동 append, self-improvement §8 잔여 배선 1번).
  유지보수 측정이라 가설 검정이 아니지만 **분모에서 빼지 않는다** — 분기 상한 16회로 적어 둔다.

### ② 귀속 (원래 M5 항목의 남은 뜻) — 화면에만

- auditor 의 Analyst 별 귀속(어느 입력이 그 달 수익을 설명했나)을 학습 탭 "랭커 입력" 표에 IC·gain 옆 세 번째 열로.
- 가중치에는 **넣지 않는다.** 귀속은 사후 설명이고 IC 는 사전 예측력이다. 둘을 섞어 가중을 만들면 지난달을 산다.

### ③ 재학습 (L0-c) — 홀드아웃 개봉 뒤, 월말마다

- 2026-11 하순 개봉 뒤부터: 매월 첫 토요일 `train_ranker --through <직전 월말>` → 새 열 하나.
- **채택 게이트**(측정 전 고정): 새 열의 직전 60세션 IC ≥ 옛 열 IC − 0.01 **그리고** ≥ `analysts.ic_threshold`. 둘 다 아니면
  새 열은 남기되 `usable_from` 을 비워 실전이 안 집는다(옛 열 유지). 게이트 결과는 학습 탭에 적는다.
- 6차 학습(ranker-sources-round6)이 채택되면 `FEATURES` 가 바뀐 `ranker-v0.2.0` 열이 생긴다. 게이트는 같다.
- 개봉 전엔 재학습 없음. "낡았다" 는 경보가 떠도 11월까지 옛 열로 간다 — 그것이 홀드아웃의 값이다.

## 배선 (설계 뒤 코드 — 순서)

1. 크론 두 줄(토 12:00 KR·US) + `scripts/measure_ic_weekly.sh`(rc 를 내보낸다, memory `silent-failure-needs-nonzero-rc`).
2. config `modelops.ranker.fail_streak`, 학습 탭 `/api/learning/gate` 에 랭커 감쇠·입력 감쇠 경보.
3. 귀속 열(auditor → 학습 탭). 4. 재학습 게이트 도구 `tools/promote_ranker.py` — 11월 개봉 뒤.

## M5 완료 기준의 새 문구

"Analyst 별 성과 귀속이 가중치 진화에 피드백" → **"랭커 IC·입력 IC 를 주 1회 자동 측정하고, 감쇠 경보와 재학습 게이트가
학습 탭에 선다(재학습 실행은 홀드아웃 개봉 뒤)."** 완료 판정: ①② 배선이 두 주 연속 자동으로 돈 것.
