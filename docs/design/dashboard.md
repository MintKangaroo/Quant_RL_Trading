# 대시보드 명세

**스택**: Flask + ECharts (CDN). 빌드 도구 없음.
**참조**: `docs/design/fund-reference.html` — 색·타이포·밀도의 기준. 구현물이 아니다.

---

## 1. 설계 입장

트레이딩 데스크 화면이지 마케팅 페이지가 아니다.

1. **고밀도** — 한 화면에서 판단이 끝난다. 스크롤은 보조 정보에만 허용
2. **추적 가능성** — 모든 숫자가 "왜 이 값인지"로 파고들어진다
3. **시점 명시** — 모든 숫자에 `as_of` 가 붙는다

**이 대시보드는 수익률 화면이 아니라 리스크 예산 화면이다.**
첫 질문은 "얼마 벌었나"가 아니라 "예산을 얼마나 쓰고 있나"다.

---

## 2. 탭 구조

상단에 4개 탭. 각 탭은 **데스크톱 1920×1080에서 스크롤 없이** 들어가야 한다.

| 탭 | 질문 |
|---|---|
| **트레이딩** | 지금 포트폴리오가 어떤 상태인가 |
| **학습** | 모델이 제대로 학습되고 있는가 |
| **데이터** | 입력 데이터를 믿을 수 있는가 |
| **뉴스·일정** | 지금 무슨 일이 벌어지고 있고, 다음에 무엇이 오는가 |

목록이 긴 패널(뉴스 40건, 지표 20건)은 **패널 안에서** 스크롤한다. 페이지를
늘리면 위쪽 지표를 보려고 매번 스크롤을 올려야 하고, 한 화면 규칙이 깨진다.
스크롤 영역의 머리글은 `position: sticky` 로 붙여 둔다 — 40행을 내려간 뒤
어느 열이 무엇인지 모르면 표가 아니라 글자 더미다.

탭 전환 시 `as_of` 는 유지된다. 타임머신 슬라이더는 탭 위 공통 영역에 둔다.

## 4. 트레이딩 탭

12컬럼 그리드. 세로 3단.

```
┌────────────────────────────┬──────────────┬──────────────┐
│ NAV vs 벤치마크 (+초과수익) │ MDD 예산     │ 오늘의 결정   │
│                            │ 게이지        │ Claude 1줄   │
├────────────────────────────┼──────────────┼──────────────┤
│ 언더워터 (12/22/30 밴드)    │ 자본 배분     │ 에이전트 15  │
├────────────────────────────┴──────────────┴──────────────┤
│ 보유 포지션 테이블 (스파크라인 포함)                        │
├──────────────────────────┬───────────────────────────────┤
│ 오늘의 후보 상위 15        │ 섹터·상관 히트맵              │
└──────────────────────────┴───────────────────────────────┘
```

### 언더워터 차트 ⭐ 시그니처
배경에 **12% / 22% / 30% 밴드**를 색으로 깐다. 보상 함수의 시각화다.
벤치마크 낙폭은 점선으로 겹친다.

### MDD 예산 게이지 ⭐ 시그니처
"8.3% / 30%" 수직 바. 상태별 문구:
- 자유구간: `자유구간 · 페널티 없음 · 여유 3.7%p`
- 페널티: `페널티 구간 · 한계까지 12.4%p`
- 급증: `급증 구간 · 신규매수 제한 · 한계까지 4.1%p`

**리스크를 안 쓰는 것도 문제라는 걸 화면이 말해야 한다.**

### 보유 포지션 테이블
종목 · 비중(목표/실현) · 손익 · 보유일 · **청산 소요일수** · 20일 스파크라인 ·
기여 Analyst. 행 클릭 → Decision Trace.

### 오늘의 결정
후보 수 · 신규매수 · 청산 · 차단(뉴스/SNS 분리) · 실현괴리 · **액션 반영률**
> 액션 반영률 30% 미만이면 경고색. 룰 시스템으로 전락했다는 신호다.

## 5. 학습 탭

```
┌──────────────────────────┬──────────────────────────────┐
│ explained_variance 추이  │ 커리큘럼 단계 (C0~C5 진행도)  │
│ (0.1 기준선 표시)         │ 오라클 카나리 통과 여부       │
├──────────────────────────┼──────────────────────────────┤
│ 학습 곡선 (에피소드 보상)  │ approx KL · entropy · grad   │
├──────────────────────────┴──────────────────────────────┤
│ Analyst별 IC 60일 이동평균 (9줄 멀티라인 + 0.03 기준선)   │
├──────────────────────────┬──────────────────────────────┤
│ 베이스라인 대비 IR        │ 시드 간 성과 분산             │
│ (벤치마크/동일가중/스코어) │ policy churn                 │
├──────────────────────────┴──────────────────────────────┤
│ 하이퍼파라미터 시행 테이블 (Optuna trial)                  │
└─────────────────────────────────────────────────────────┘
```

### 핵심 위젯

**explained_variance** — 0.1 기준선을 그린다. 0 근처에 붙어 있으면 학습 실패다.
`rl-training.md` §3 의 6가지 원인 중 어디까지 배제했는지도 함께 표시한다.

**Analyst IC 멀티라인** — 9개 Analyst의 60일 IC. **0.03 기준선**을 그어
어느 것이 가중치를 받고 있는지 한눈에 보이게. 하락 추세면 알파 소멸이다.

**베이스라인 대비 IR** — 스코어 비례(M3 룰)를 못 이기면 RL을 쓸 이유가 없다.
이 패널이 그 답을 항상 보여준다.

**시드 간 분산** — 하이퍼파라미터 간 차이보다 크면 그 결과는 노이즈다.

## 6. 데이터 탭

소스별 커버리지 · 결측률 추이 · **지연 실측 분포(p50/p90)** ·
universe 종목 수 추이 · 정정공시 발생 건수 · 최근 수집 실패 ·
**진행 중인 작업(백필·IC 측정 진행률)** · LLM 월 비용 · 캐시 적중률

진행률 패널은 뉴스·일정 탭에 있었다. 수집이 어디까지 갔는지는 "지금 무슨
일이 벌어지고 있나" 가 아니라 **"입력을 믿을 수 있나"** 의 답이라 이 화면이
제자리다. 이 값은 ``as_of`` 로 되감기지 않는다 — 운영 상태이지 관측된
사실이 아니라 창고에 과거가 없다.

## 8. 밀도 규칙

고밀도는 "작게 만들기"가 아니라 **여백을 정보로 바꾸기**다.

- 패널 헤더 높이 28px, 패딩 8~10px. 카드마다 큰 여백을 두지 않는다
- 테이블 행 높이 26px, 본문 12px, 숫자 12.5px
- **테이블에 스파크라인을 넣는다.** 별도 차트 패널보다 밀도가 높다
- 숫자는 `tabular-nums` 고정폭. 자릿수 정렬 필수
- 축 레이블·범례는 최소화. 알 수 있는 건 지운다
- 애니메이션 없음 (`animation: false`). 움직이는 대시보드는 아마추어처럼 보인다
- 폴링: 장중 5초 / 장외 1분

## 8-2. 뉴스 · 일정 탭

| 패널 | 내용 |
|---|---|
| 다음 발표 | 가장 가까운 지표 + 남은 시간 |
| 거시지표 — 발표 완료 | **지표당 한 줄.** 실측 · 직전 · 변화 |
| 거시지표 — 예정 | 발표 시각 + 남은 시간 |
| 발표 해석 | 서프라이즈 · 시장 반응 · Claude 해설 |
| 뉴스 · 공시 | 최신순. 같은 기사는 접고 걸린 종목을 함께 |

**지표당 한 줄이다.** "최근 N건" 으로 자르면 발표가 잦은 시장이 화면을
독차지한다 — 실제로 미장 15건이 국장 4건을 밀어내 국장이 1건만 남았다.
이 화면의 질문은 "최근 무엇이 발표됐나" 가 아니라 "지금 각 지표가 얼마인가" 다.

### "실시간" 은 as_of 를 안 준 상태다

1분마다 갱신하되 **`as_of` 가 주어지면 갱신을 멈춘다.** 타임머신을 켜 둔 채
화면이 현재로 흘러가면 사람이 보고 있는 시점이 조용히 바뀐다.

### 발표 해석 — 숫자는 코드가, 해설은 Claude 가

서프라이즈와 시장 반응은 **계산**이라 재현 가능해야 하고, 지표 → 정책 경로 →
시장 함의는 **해석**이라 규칙으로 못 적는다. 그래서 숫자는 코드가 만들고
Claude 에게는 그 숫자를 주고 해석만 시킨다. **이 출력은 보상 함수에 들어가지
않는다** (불변식 8).

"예상치" 는 직전값이지 컨센서스가 아니다(유료라 못 구한다). 시장이 이미
반영한 변화까지 서프라이즈로 세므로 과장돼 있고, 그 한계를 화면에 적는다.
반면 시장 반응은 실측이라 해석의 무게를 그쪽에 싣는다.

### 색 규칙의 적용 — 거시지표 변화에는 색을 쓰지 않는다

§10 이 "색은 손익과 경고에만" 이라고 정한다. 거시지표의 전월 대비 변화는
손익이 아니다. 부호에 좋고 나쁨을 입힐 수도 없다 — **실업률 상승과 GDP
상승은 같은 부호지만 반대 뜻이다.** 방향은 부호로만 보여주고 해석은 사람에게
맡긴다. 반면 **시장 함의 배지**(위험선호/위험회피)는 손익 방향이므로 색을 쓴다.

## 8-3. 마켓 탭 — 왼쪽 국장 · 오른쪽 미장

이 화면의 질문은 "우리 포트폴리오가 어떤가" 가 아니라 **"지금 시장이 어떤가"**
다. 그래서 NAV·낙폭·손익은 여기 없다(그건 트레이딩 탭과 `accounting/` 의 것이다).

```
KPI: 국장 대표지수 · 국장 상승:하락 │ 원달러 │ 미장 상승:하락 · 미장 대표지수
────────────────────────────────────────────────────────────────
대표 지수 4종 — 기준일 100 정규화 (두 칸에 걸침)
┌──────────── 국장(KR) ────────────┬──────────── 미장(US) ────────────┐
│ 지수 (대표 + 나머지 스크롤)        │ 지수 (대표 + 나머지 스크롤)       │
│ 시장 폭 (상승/하락/보합·거래대금)   │ 시장 폭                          │
│ 오늘 움직인 종목 (상승·하락·거래대금)│ 오늘 움직인 종목                  │
│ 시가총액 상위                     │ 시가총액 상위                     │
│ 시가총액 맵 (트리맵)               │ 시가총액 맵                       │
│ 거시지표 — 발표 완료               │ 거시지표 — 발표 완료               │
└──────────────────────────────────┴──────────────────────────────────┘
```

**두 칸은 같은 패널을 같은 순서로 든다.** 한쪽에만 있는 패널을 만들면 좌우
밀도가 갈라지고, 그러면 "미장은 원래 볼 게 없다" 처럼 보인다 — 실제로는
없는 것이 아니라 **아직 안 받은 것**이다. 그래서 렌더러도 하나이고 시장
코드만 바꿔 두 번 돈다(`static/market.js`). 두 칸이 같은 시장을 그리는
사고는 API 200 · 렌더러 정상으로도 일어나므로 테스트가 따로 잡는다
(`tests/dashboard/test_market_render.py`).

- **상단 차트는 대표 지수 넷이다** — 코스피·코스닥·나스닥·S&P 500. 좌우로
  갈리기 전에 한 그림으로 둔다. 이 자리의 질문은 "어느 시장이 앞서 가나" 이고,
  그건 네 선을 겹쳐야만 보인다. 칸 안에 하나씩 넣으면 두 그림을 눈으로 번갈아
  보며 풀어야 한다.
  - **기준일 100 으로 정규화한다.** 코스피 ~4,000 · 코스닥 ~900 ·
    나스닥 ~26,800 · S&P500 ~7,800 을 한 축에 원값으로 그리면 코스닥이 바닥의
    직선이 된다. 넷으로 쪼개는 대신 정규화를 고른 것은, 쪼개면 절대 수준은
    살아도 위의 질문이 안 풀리기 때문이다. **정규화했다는 사실을 화면이
    말한다** — 머리글에 기준일과 기준값을 적고, 정규화가 지운 절대 수준은
    범례가 오늘 종가로 되돌려 준다.
  - **기준일은 넷이 다 있는 첫 세션이다.** 각자 자기 첫 세션에서 100 으로
    잡으면 벌어진 간격이 성과 차이가 아니라 출발선 차이가 된다.
  - 색은 시장(국장·미장), 선 모양은 역할이다 — **실선이 `config.benchmark` 가
    정한 대표 지수**, 점선이 그 곁 지수. 초록·빨강은 이 화면에서 등락 하나만
    뜻해야 하므로 계열 구분에 태우지 않는다.
  - **변동성 지수(VIX·VXN·RVX)는 여기 없다.** 가격지수가 아니라서 정규화해
    같은 축에 두면 급등이 수익률로 읽힌다. 지수 목록에는 두되 **가격지수와
    갈라서** 놓고, 등락에 손익 색을 쓰지 않는다 — VIX 상승은 수익이 아니다.
- **원달러는 KPI 로 남는다.** 어느 한쪽의 지표가 아니라 두 시장 사이의 다리라
  좌우로 갈리기 전의 공통 줄에 있어야 한다 — 국장 칸에 넣으면 미장 시총을
  환산하는 숫자가 국장 것처럼 읽힌다. 상단 차트 자리는 지수가 가져갔고,
  환율은 KPI 카드와 그 스파크라인으로 판다.
- **원·달러를 한 그림에 섞지 않는다.** 시가총액 맵은 KR·US **완전히 다른 맵
  둘**이다. 원화 시총이 절대적으로 더 커서 한 트리에 두면 스케일이 뒤섞인다.
  응답이 통화(`currency`)를 같이 실어 화면이 억원/억달러를 갈라 적는다.
- **대표 지수는 `config.benchmark` 가 정한다.** 우리가 실제로 견줘 평가받는
  지수를 화면의 대표로 삼는다(불변식 10). 그 이름이 창고에 없으면 "아직 안
  들어왔다" 고 적을 뿐 **다른 지수로 바꿔치기하지 않는다** — KRX 300 을
  코스피라 부르는 순간 화면이 거짓말을 시작한다. 가격지수라 배당이 빠진
  만큼 우리가 유리하게 보이므로 `가격지수 · 배당 미반영` 배지를 계속 단다.
- **나머지 지수는 자르지 않는다.** 국장 44종·미장 10종이라 그냥 깔면 왼쪽이
  몇 배 높아진다. 줄 수를 자르는 대신 **패널 높이를 고정하고 안에서
  스크롤**한다 — 자르면 오늘 조용했던 코스닥이 목록에서 사라지는데, "안
  움직였다" 도 화면이 말해야 하는 사실이다.
- **시장 폭·움직인 종목은 시세만으로 만든다.** 미장은 시총·수급·재무가 아직
  없어도 이 두 패널이 국장과 같은 밀도로 찬다. 그리고 지수 하나로는 "지수는
  올랐는데 종목의 70%는 내렸다" 를 볼 수 없다. 등락을 못 잰 종목은 보합 칸에
  넣지 않는다 — 따로 센다.
- **없는 것은 이유를 적는다.** 값이 비면 빈 표가 아니라 왜 비었는지를 띄운다.
  빈 표는 조인 버그처럼 보여서 엉뚱한 데를 파게 만든다.

1280px 아래에서는 두 칸이 세로로 접힌다. 넓은 표는 **자기 컨테이너 안에서**
가로 스크롤한다 — 페이지 본문이 가로로 밀리면 좌우 배치 자체가 무너진다.

## 9. API 규약

```
GET /api/trading/positions?as_of=2024-03-05T15:30:00+09:00
```

- **모든 엔드포인트가 `as_of` 를 받는다. 예외 없음**
- 응답에 `as_of` 를 되돌려준다
- 임계치(12/22/30, IC 0.03, 반영률 30%)는 `store.config` 에서 읽는다.
  하드코딩하면 학습 설정과 어긋난다
- Jinja는 뼈대만. 데이터는 전부 `/api/*` JSON
- 탭별로 엔드포인트를 나눈다. 안 보는 탭의 데이터를 부르지 않는다

## 10. 시각 토큰

```
배경   #070A0F   패널   #0D1219   패널2  #141B24
머리글 #111823   보더   #1E2733   본문   #E6E9EE
보조   #8A93A0   흐림   #5A626D   경고   #F5A524
상승   #22C55E   하락   #EF4444   벤치마크 #6B7280
강조   #38BDF8
```

- 다크 기본. 색은 손익과 경고에만. 나머지는 무채색
- **상승 = 초록으로 통일.** 국장·미장을 함께 보므로 화면마다 다르면 사고가 난다.
  2026-08-14 에 빨강(한국식)에서 뒤집었다 — 터미널 시안이 미국식이고,
  **어느 쪽이든 한 벌이기만 하면 된다**. 갈라지는 것만이 사고를 만든다
- **강조색(#38BDF8)은 손익이 아닌 것에만.** 선택된 탭·초점·구조선이다.
  손익 색과 겹치면 "이 색이 손실인가 선택인가" 를 매번 생각하게 된다
- 부호는 색만으로 말하지 않는다. ▲▼ 를 같이 찍는다 — 색각 이상에서
  초록과 빨강은 같은 회색이다
- 타이포: `IBM Plex Sans KR`(UI) + `IBM Plex Mono`(모든 숫자)
- `prefers-reduced-motion` 존중, 키보드 포커스 가시화
