## 6. 고칠 것 — 계획만, 실행 안 함 (승인 필요)

### 정정 (append-only, `data/_paper` 오버레이)

`orders` 에 `KR-2026-09-21|KR:005945|1` 의 **rev 3** 한 행을 append:

- `status = rejected`, `reason = "미도착 확인 — CSPAQ13700 2026-09-22 전체 36행에 없음, 번호 86 은 조각 0(저널 08:40:44); 확인 2026-09-22 t0425·2026-10-04 재조회"`

- `rejected` 를 고르는 이유: 기존 상태 집합 안의 종결 상태이고, 예약·대사·추격 어느 쪽도 다시 집지 않으며, `trades`·NAV 에 닿지 않는다.
  `refresh_order_states` 는 `execution_events` 에 의도가 있는 행만 되적으므로(이 조각엔 사건이 0건) 덮어쓰지 않는다.
- 대안: 새 상태 `not_received`(뜻이 더 정확) — 대시보드 "대기/취소" 분류·`UNRESOLVED_STATUSES` 등 상태를 나열하는 곳을 다 고쳐야 해서 이번엔 권하지 않는다.
- 039200 조각 3 은 증권사 대조를 먼저 하고, 미도착이면 같은 정정.
