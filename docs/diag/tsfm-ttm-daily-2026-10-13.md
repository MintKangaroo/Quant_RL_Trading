## 질문

지금 쓰는 TTM(`granite-timeseries-ttm-r2` main, 문맥 512, 분·시간 해상도용)에는 일봉 256개를 512로 앞채움(관측표지 0)해서 넣는다.
IBM 이 낸 **일봉·주봉 지원판 r2.1**(빈도 토큰 `D`=8 을 받는 `-ft-` 가지)이 같은 자리에서 더 나은가.

## 정의 — 10/9 와 같다

- 국장, 창 A(2026-02~06, 19세션) · 창 B(2025-03~2026-01, 44세션), 5세션마다, 원 거래대금 20일 평균 상위 300 보통주.
- 라벨 `r = close(t+6)/close(t+1) − 1`. 예측 수익 `r̂ = p̂(t+6)/p̂(t+1) − 1`(10/9 정의 그대로 — 지평 1..6 중 2..6 구간).
- 세션별 Spearman IC → 평균 · NW t(lag 1) · 양수 비율. D1/D10 = 세션마다 r̂ 10분위의 5일 수익 − 세션 300 평균, 세션 평균.
- V0 순위상관 = 세션마다 r̂ 대 V0 r̂ 의 Spearman 평균.
- **재현 확인**: V0 를 같은 하네스로 다시 돌린 예측이 10/9 `ttm-KR-*-L256.npz` 와 최대 오차 0.0 — IC +0.0895 / +0.0828 이 그대로 나온다.

## 읽기

1. **일봉판이 낫다고 말할 수 없다.** 창 A 에서는 r2.1 이 +0.02~+0.03 높고, 더 긴 창 B 에서는 −0.015~−0.03 낮다. 대응 차이는 어느 쪽도 t 1.1 을 넘지 않는다. 두 창을 세션 수로 합치면 V0 +0.085 · V1 +0.083 — 같다.
2. **빈도 토큰은 효과가 있다(같은 r2.1 가중치 안에서).** V3(D) 대 V3o(oov): 창 A +0.110 대 +0.064, 창 B 는 같다. 그래도 V0 를 넘지 못한다.
3. **우리가 쓰는 쪽(패자 판별, D1)은 V0 가 가장 세다.** IX-T·TF 는 TTM 하위 분위를 쓴다. 창 B D1 이 V0 −1.38% 대 V1 −0.54% · V3 −1.19%. r2.1 의 A 창 이득은 주로 D10 쪽(상위 분위가 0 근처로 올라옴)에서 왔다 — 상위로 옮겨 쓰지 않는 신호에서의 이득이다.
4. **r2.1 은 V0 와 다른 신호다**(순위상관 0.45~0.69). 그래서 평균 순위 결합이 창 A 에서 +0.029(t 1.8)였지만 창 B 에서는 0 이다. 일관되지 않는다.
5. 비용은 문제가 아니다. 2,600 종목 하루 추론이 V1 1.6초 · V2 3.7초.

## 결론

- **일봉 r2.1 은 현행 main 보다 낫지 않다**(두 창 합쳐 IC 차이 ≈ 0, 창마다 부호가 바뀜, 패자 판별 D1 은 오히려 약함).
- **새 후보 등록 가치 없음**(11/23 금고용 10/22 고정 대상에 넣지 않는다). TF/IX-T 는 현행 main 그대로 둔다.
- 남겨 둘 실마리 하나: V0+V1 결합(창 A t 1.8, 창 B 0) — 전방 기록 없이 등록할 근거는 못 된다. 다시 볼 때는 금고 뒤 새 창에서 결합만 본다.
- TTM-r3 는 tsfm_public 을 올려야 해서 미측정이다. 올린다면 밤 신호와 분리된 별도 가상환경에서 한다.
