### C. 정답 재정의 GBM

- **수학적 사실 먼저**: "K200 대비 초과수익의 세션 안 순위" 는 현행 정답(세션 안 rank-gauss)과 **같다** — 그날 K200 수익은 모든 종목에 같은 상수라 순위를 바꾸지 않는다.
  그래서 K200 을 정답에 넣는 의미 있는 방법은 종목별 노출로 빼는 것이다.
- 피처 = C0 의 6점수(rank-gauss), 하이퍼파라미터 = 시행 L(`trial_ranker_kit.fit` 그대로, 스레드 2), 블록 = C0 규격(20세션 · 첫 블록 155 · 학습 끝 = 블록 시작 − 퍼지 5 − 엠바고 5). 국장 단독. 시드 0~4.
- 정답(세 정답 모두 **같은 행** — h5 라벨·β·시총이 다 있는 행에서 배운다):
  - **T0** = r5 의 세션 안 rank-gauss(현행 정답의 국장 단독 재현 — 대조)
  - **T1** = (r5 − β·K200 r5) 의 rank-gauss. β = 결정 t 종가까지 일수익 120일(최소 60) K200 회귀 기울기, [−1, 3] 로 자름
  - **T2** = 세션마다 r5 를 [업종 더미, β, log 시총] 에 최소제곱한 잔차의 rank-gauss
  - r5 는 [−50%, +100%] 로 자른 뒤 쓴다(회귀 이상치)
- 판정 없음. 사다리(T1·T2 대 T0, n_tests 2)와 손실표로 비교만 한다. 결과가 강하면 "11/23 등록 초안 가능성" 만 적는다.
- 재현 검산: T0 대 C0 이음(같은 창) — 학습 표본(국장 단독 대 합동)만 다르다.

### E. 종합 — "정보는 있는데 번역에서 샌다"

1. **정보는 있다**: C0 IC +0.085(t 17), BE2 는 C0 위에 ΔIC +0.017(t 5.7, 급등장 빼도 t 4.5). 패자 쪽 정보가 승자 쪽의 세 배.
2. **특수 구간 밖에서 가장 큰 누수는 비용**(비용 전 +10.1% → 비용 후 −0.6%, −10.7%p). 다음이 평활·완충(−4.9%p)과 V6(−4.6%p).
3. **대 K200 의 큰 손실(−25~−31%)은 2025~26 급등장 한 구간의 스타일**이다 — 모든 모델·레버·정답에서 같고, 특수 구간을 빼면 −1~+10% 로 0 근처. 사용자 원칙대로 '특수' 로 따로 본다.
4. 레버: **회전(R20)이 유일하게 특수 구간 밖에서 t ≥ 2(+10.1%p)**, 비용 인지 N100·θ1, 잔차 정답(T2 — 회전을 반으로) 순. 넓게 들기(N50·N100)는 효과 없음. 지수−패자는 대용 지수 실행 오차가 알파보다 크다.
5. AR(내부자)·재심 7건은 칸 ② 에서 정보 증가가 없다. 미장 내부자는 **스타일 잔차화**하면 문헌 방향의 독립 신호(매도 −0.021~−0.034, 매수 +0.016, t 4~10)가 보인다 — 새 재료 후보.
