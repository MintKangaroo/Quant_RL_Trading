## 왜 — 종목 축 실패와 다른 층

종목별 외국인 수급(flow_kr)은 횡단면 IC −0.012 로 실패했다(공개 정보·가격에 이미 반영). 이 진단은 **횡단면이 아니라 시장 수준의 시계열**
— 외국인이 시장 전체로 들어오는 시기를 미리 알 수 있나, 그걸로 노출(배수)이나 대형주 비중을 기울이면 값을 하나 — 를 묻는다.
비용 분해·헤지 진단에서 격차의 주인은 대형주(K200) 랠리를 못 탄 것이었다(`docs/diag/hedged-alpha-sleeve.md`, `docs/diag/paper-cost-decomposition-2026-10.md`).
외국인 순매수는 대형주에 몰린다 — 그 유입을 앞서 읽을 수 있으면 바로 그 격차를 겨눈다.

## §1 측정 정의 (돌리기 전 고정)

### 기간 · 정렬

- 세션: K200 지수가 있는 날. **신호 d ∈ [2021-09-10, 2026-06-30]**(flows 20세션 누적이 차는 첫날부터), 성과는 **d+1 종가 → d+1+h 종가**
  (판정 kit 의 t+1→t+2 와 같은 한 세션 집행 지연). **성과 구간 끝이 2026-06-30 을 넘는 관측은 버린다**(금고 7/1~ 앞).
- 국면(구간, 달력으로 고정 — 결과 안 봄): **하락** 2021-09-10~2022-09-30 · **박스** 2022-10-01~2024-12-31 · **급등** 2025-01-01~2026-06-30.
- **독립 관측 수**를 표마다 적는다: 겹치는 지평이라 h=5 면 N/5, h=20 이면 N/20(약 60). t 는 Newey-West(래그 = h).

### 변수

- **외국인 시장 순매수 F_k(d)** = Σ_{최근 k 세션} [그날 전 종목 외국인 `net_value` 합 ÷ 그날 전 종목 시총 합], k = 1·5·20. (기관합계·개인도 같은 식으로 만들어 기록만.)
  종목이 빠진 날(행 없음)은 0 으로 채우지 않고 그대로 합한다(없는 행 = 그 주체가 손대지 않음).
- **K200** = 지수 수익. **대형 EW** = 시총(d 종가) 상위 50 동일가중, **중소형 EW** = 시총 순위 201~1000 동일가중(매일 재조정, 일수익 |r|>50% 는 사고로 뺌, 수정주가).
  **대형−중소형 스프레드** = 대형 EW − 중소형 EW.
- **원달러 FX(d)** = 미국달러선물 **최근월** 정산가. 일변화는 **같은 월물끼리**(롤 날짜에 월물 간 차이를 수익으로 섞지 않는다).
- 매크로 신호(결정 d 기준, 다섯 개만):
  - **X1** 원달러 20세션 로그변화 · **X2** 원달러 5세션 로그변화 (+ = 원화 약세)
  - **X3** 달러선물 내재 금리차 20세션 변화 — 내재 금리차 = (차근월/최근월 − 1)×365/만기일수 차(만기 = 각 월 셋째 월요일), 원화−달러 단기금리차의 대용
    - **§1 정정(2026-10-06 17:2x, 분석 실행 전 · 결과 안 봄)**: 차근월 → **만기가 최근월+12개월에 가장 가까운 월물**. 캐시를 파싱해 보니 최근월·차근월은 만기 차가 한 달이라
      호가 단위 0.1원이 내재 금리차에 연 0.1%p 단위 잡음을 만든다(만기 직전엔 한 세션에 1.7%p 튐). 12개월 차면 같은 단위가 0.01%p 다. 미결제가 없는 원월물 정산가는 KRX 이론가(시장 스왑포인트 기반)다.
  - **X4** 한미 10년 금리차(국고 10년 지표 − UST10Y) 20세션 변화
  - **X5** 미 커브 기울기(UST10Y − UST2Y) 20세션 변화
  - 미 국채는 결정 d 에 뉴욕 d−1 까지만(위 공표 시각).

### (a) 외국인 순매수 → 다음 수익

F_1·F_5·F_20(d) 각각 × 다음 h=5·20 세션의 K200·대형 EW·중소형 EW·대형−중소형 수익. 지표: 스피어만 상관(시계열 IC)과 z 회귀 기울기의 NW t,
전체 + 국면 셋. 3×2×4 = 24 칸 — **다중 검정이라 |t|>2 하나로 결론 내지 않는다**(칸 수를 같이 적는다).

### (b) 매크로 → 다음 외국인 순매수

X1~X5 각각 × 미래 외국인 순매수 F_h(d+h)(= d+1..d+h 합, h=5·20). 지표 (a) 와 같음 + **자기 과거 F_20(d) 를 통제한 부분 t**(외국인 순매수는 지속성이
있고 환율과 같이 움직인다 — 매크로가 과거 수급 위에 더 주는 게 있는지).
**인과 방향**: 일별 F_1 과 원달러 일변화의 시차 상관 −10~+10 세션(음수 시차 = 환율이 먼저), 그리고 5세션 블록으로 같은 표.

### (c) 노출 · 대형주 기울기 — 변형은 이것뿐(결과 보고 안 고른다)

- **예측 유입 P(d)**: 미래 F_20 을 X1~X5 에 확장창 OLS 로 회귀. 학습 표본은 **성과가 d 전에 다 실현된 관측만**(목표 끝 ≤ d, 즉 신호일 ≤ d−20), 최소 120 관측,
  매월 첫 세션 재적합. P 를 확장창 평균·표준편차로 z(최소 60관측).
- 기록(변형 선택에 안 씀): P 의 **표본 밖** IC — P → 실제 다음 20세션 외국인 순매수, P → 다음 20세션 K200.
- 매핑(V6·HMM 과 같은 0.05 반올림·데드밴드 0.10):

| 변형 | 정의 |
|---|---|
| **N0** 지수 100% | K200, 노출 1.0 |
| **V6** | 실전 규칙 국면 배수(`tools/v2_hmm_exposure.v6_path`, K200 국면 · 2세션 확인) |
| **HMM** | `tools/v2_hmm_exposure.hmm_path`(시행 BB 의 E2 매핑) |
| **C1** 예측 유입 노출 | k = clip(1 + 0.25·z_P, 0.5, 1.0) |
| **C2** 실현 수급 노출 | C1 과 같은 식에 z_P 대신 **과거 F_20 의 확장창 z** (매크로 없이 수급 모멘텀만) |
| **C3** HMM ∧ 예측 유입 | k = min(k_HMM, k_C1) |
| **T0** 고정 반반 | 0.5·K200 + 0.5·중소형 EW (기울기 없는 같은 구성 — 대조) |
| **T1** 대형 기울기 | a·K200 + (1−a)·중소형 EW, a = clip(0.5 + 0.25·z_P, 0, 1) |

- 노출 변형(N0·V6·HMM·C1~C3): r = k·r_K200 − |Δk|·0.41%(현금 수익 0, `diag_bear_2022.apply_exposure` 와 같은 식).
  기울기 변형(T0·T1): r = a·r_K200 + (1−a)·r_중소형 − 2|Δa|·0.41%(한쪽 팔고 다른 쪽 산다). 중소형 EW 의 매일 재조정 비용은 T0·T1 에 같이 빠져 있다(상대 비교만).
- k·a 는 결정 d 의 정보로 정하고 d+1→d+2 수익에 적용한다(V6·HMM 도 같은 정렬로 맞춘다 — 세션 e=d+1 의 경로 값 = e 전날까지 정보).
- 지표: 연수익·변동성·샤프·MDD·**K200 대비 IR**·β·평균 노출·전환 횟수, 전체와 국면 셋. 평가 창 = C1 이 처음 정의되는 날 ~ 2026-06-30(모든 변형 공통).

### 읽는 법(미리)

- (b) 에서 X 가 과거 수급 통제 후에도 |t|≥2 가 아니면 "매크로가 유입을 예측한다" 는 근거가 없다 — 그러면 (c) C1·C3·T1 은 잡음 매핑이고 결과가 좋아도 우연으로 읽는다.
