# 진단 — "장기이평선 돌파 + 거래대금 + 이평선 완만" 매매법 (2026-10-10, 사용자 요청: 인스타 '모의투자대회 수상자 매매법')

> **규칙은 결과를 보기 전에 이 절에 고정했다(커밋 시각이 증거).** 진단이지 시행 등록이 아니다 — 채택 판단은 하지 않고, 값이 있으면 사전등록을 따로 제안한다.
> 자료: 국장 보통주 보정 종가·원 거래대금, **2026-06-30 까지만**(금고 창 7/1~ 은 열지 않는다).

## 원문 → 숫자

| 원문 | 숫자(고정) |
|---|---|
| 거래대금이 실린 캔들이 장기이평선을 뚫는다 | 종가가 **120일 단순이평** 을 아래→위로 교차(전날 종가 ≤ 전날 이평, 오늘 종가 > 오늘 이평) **그리고** 오늘 거래대금 ≥ 직전 20일 평균의 **2배** |
| 장기이평선 각도가 완만해진다 | 이평 20일 변화율 \|MA_t / MA_{t−20} − 1\| ≤ **2%** |
| 장기이평선이 캔들 밑으로 깔린다 | **확인**: 돌파 다음 3세션(t+1~t+3) 종가가 모두 이평 위 → t+3 종가에 진입 |
| 재료 | 숫자로 못 바꾼다 — 재지 않는다 |

- **진입**: 주 변형 = 확인 뒤 t+3 종가. 기록 = 확인 없이 t+1 종가.
- **성과**: 진입 뒤 5·20·60세션 수익 − 같은 기간 거래가능 동일가중(아래 우주) 수익. 수수료·세금 편도 0.41% 를 한 번 뺀 값도 적는다(왕복 0.82%).
- **우주**: 그날 20일 평균 거래대금 ≥ **10억원**, 이력 140세션 이상. 같은 종목은 60세션 안 재신호를 세지 않는다(중복 표본 막기).
- **대조(신호 없는 같은 구성, 복기 규칙 9)**: C-교차 = 120일 이평 상향 교차만(거래대금·완만·확인 조건 없음). 조건이 값을 하는지 = 주 변형 − C-교차.
- **통계**: 결정일별 평균 → 날짜 단위 NW t(lag = 지평−1). 국면 셋: 2021-08~2022-12(하락) · 2023-01~2024-12(박스) · 2025-01~2026-06(급등). 적중률 = 초과 > 0 비율.
- **기록 변형(기준 없음)**: 200일 이평.
- **"값 있음" 의 정의(미리)**: 주 변형 20세션 비용 후 초과 > 0 이고 NW t ≥ 2, 그리고 세 국면 모두 양수, 그리고 C-교차보다 높다. 하나라도 아니면 "값 없음".
