## 0. 전제 — 이번 스캔이 따른 것

- **무료만**(FnSpace 연 70만원 경로는 닫힘, 다시 제안 안 함). 선물·파생 **매매** 제외, 파생 **자료**를 신호로 쓰는 것은 허용.
- **robots 금지 호스트 제외**(Yahoo, data.krx.co.kr 스크래핑, 한경·네이버·FnGuide 컨센서스). 공식 API 만: DART OpenAPI · KRX Open API · SEC EDGAR · data.go.kr · FRED · ECOS · LS.
- **이력 ≥ 3년 + 공표 시각**(observed_at 을 지어내지 않을 수 있어야 함).
- 지금까지 일관된 알파는 **패자 피하기(숏 다리), 동일가중 기준**이다([[ranker-skill-is-losers]] · 공매도 금지기 분할: 패자 알파 상당 부분이
  금지 기간에 몰림). 그래서 "무너질 종목" 재료와 **두 시장 공통** 재료를 우선했다.
- **BA 교훈**: 개수·수준 피처는 스타일 대리가 된다 → 모든 후보에 "스타일 대리 위험" 을 적었다.
- **지평 주의**: 랭커 타깃은 h5 다. 문헌의 많은 이상현상(아래 1·2번)은 **월~연 단위**로 쌓인다 — h5 IC 로 재면 작게 보일 수 있다.
  이건 등록 때 "주 기준을 무엇으로 하나" 문제로 넘긴다(아래 §3).

## 3. "이거 실험해보자" — 추천 셋

### ① N1 순주식발행 · 자산성장 (지금 바로, 수집 없음)
국장 이상현상 연구에서 크기 그룹을 가리지 않고 살아남은 유일한 헤지 수익이 순주식발행이었고(Yoon·Son 2014), 미국에서도
Pontiff·Woodgate 이후 숏 다리의 대표 재료다. 우리 창고에는 이미 KR 일별 상장주식수(`LIST_SHRS`)와 US 발행주식수(EDGAR companyfacts,
`filed` 시각 포함)와 총자산이 있어 **수집기가 하나도 필요 없다** — 대장 운영 규칙("수집기 없이 되는 것이 먼저")에 정확히 맞는다.
G2(희석 공시 **건수**, 기각)와의 차이는 입자다: 국장 패자의 전형인 CB 전환청구·BW 행사·제3자배정은 공시가 한 번이어도 주식수는
여러 달에 걸쳐 늘어난다 — 그 "물량" 을 직접 센다. 피처(안, ≤3): `nsi_12m`(12개월 log 주식수 변화, 분할·무상 보정) · `nsi_1m`(최근 1개월,
전환 물량 출회) · `asset_growth`(총자산 YoY). **등록 전 필수**: β·log 시총·변동성·B/M 과의 ρ(BA 교훈), `raw_event_dilution`·`dilution_60`
과의 ρ, 분할·무상증자 보정 검산(보정 실패가 가짜 "발행" 을 만든다). 주 기준은 G11 과 같은 상위 N 틀 + 하위 십분위 z-수익 기록.
**한계**: 문헌 효과는 월 단위 — h5 ΔIC 는 작게 나올 수 있으니 판정 창(10/13 이후 안 본 창)과 지평을 등록에 미리 박는다.

### ② N2 정기보고서 문구 변화 (Lazy Prices, 두 시장)
Cohen·Malloy·Nguyen(2020 JF)은 "보고서를 크게 고쳐 쓴 회사" 가 이후 이익·뉴스·**파산**까지 나빠지고, 시장은 공시일에 반응하지 않다가
나중에 천천히 값을 매긴다는 것을 보였다(변경 기업 숏, 월 최대 188bp, 되돌림 없음). 이는 우리가 찾은 유일한 일관 알파 — "나쁜 것
피하기" — 와 같은 방향이고, 지금까지 쓴 공시 재료(건수·사건 파서·TX 임베딩)가 전부 **사건 공시**였던 것과 달리 **정기보고서의 변화량**이라
정보가 새롭다. DART `document.xml` 수집 배관이 이미 있어 대상 유형(정기공시)만 넓히면 되고, 미장은 EDGAR 일별 색인을 이미 쓴다.
먼저 **창 밖 표본 수백 건으로 비용 확인**(사업보고서 크기·섹션 추출 성공률·옛 접수번호 원문 제공 범위)을 하고, 저장은 섹션 텍스트 압축만.
피처(안): 직전 동종 보고서와의 코사인/자카드 유사도(전체·위험 관련 섹션) 2개. **위험**: 한국 재현 연구 없음, 2014 이후 감쇠 미확인,
효과가 월 단위, 저장 공간(SSD 여유·HDD 불량). 그래서 순위 2.

### ③ N3 국장 주식선물 괴리·미결제 (공매도 금지기 숏 수요)
10/9 분할 진단에서 패자 알파의 상당 부분이 **공매도 금지기**에 몰렸고 재개 뒤 대형에선 사라졌다. 금지기 동안 숏 수요는 개별주식선물로
옮겨 갔고(미결제 +27%, 외국인 순매도, 현선 괴리 −3% 초과 보도), 해외에선 숏 수요의 가격(대차수수료)이 수익을 예측한다는 것이 최근 JFE 에서
다시 확인됐다. KRX Open API 파생 카테고리가 주식선물 일별매매를 무료로 주므로, 종목별 **이론가 대비 괴리**(금리·배당 보정)와 **미결제 변화/시총**
으로 "선물로 숏 당하는 종목" 을 잴 수 있다. 대형·중형 200여 종목뿐이라 전 유니버스 랭커보다 **IX/IX-T 의 K200 안 하한**(지수 − 패자) 재료로
맞다. 먼저 할 것: 파생 카테고리 승인 → 필드 명세(미결제·정산가·기초자산 코드) 확인 → 이력 시작일 실측(수익은 안 봄). 공매도 축이라
사전확률은 보수적으로 잡고, 금지기·재개 후를 나눠 보고하도록 등록에 박는다(재개 후엔 대차가 다시 열려 신호가 약해질 것이 예상됨).

## 4. 미확인 목록(등록 전 확인할 것)
- 창고 `prices.shares`(KR) 의 실제 적재 시작일과 분할·무상증자 보정 여부.
- DART `document.xml` 이 2015 이전 정기보고서 접수번호에 원문을 주는지, 사업보고서 평균 크기.
- KRX Open API 주식선물·주식옵션 응답 필드명과 시작일, 파생 카테고리 승인 소요.
- SEIBro 오픈API 에 의무보호예수 항목이 있는지(N8).
- Lazy Prices 한국 재현·2014 이후 감쇠, 국장 주식선물 basis → 수익 학술 근거.
