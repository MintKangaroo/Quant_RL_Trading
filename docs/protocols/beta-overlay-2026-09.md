## 전략 대리 시계열 (측정 전 고정)

창고엔 ETF 시세가 없고 백테스트 루프는 무거워, 현행 규칙을 그대로 옮긴 **대리(proxy)** 로 잰다.
- 점수: 랭커 시행과 같은 캐시 `data/_diag/scores-{fundamental,risk}-KR.pkl` (300세션 2025-05-21~2026-08-11).
- 현행 규칙(2026-08-29 `analyst_weights`): 알파 = **fundamental 하나**(event 는 한계기여 0 으로 가중치 0),
  risk 는 제약 — `selector.risk_floor_percentile`(하위 20%) 컷. 남은 것 중 fundamental 상위 24, 동일가중.
- 수익: 수정 종가, 진입 지연 1일(t 결정 → t+1 종가 진입 → t+2 종가), 편도 0.41% 회전 비용. 일수익 ±50% 초과 결측.
- 벤치마크: KOSPI200 지수(`indices`), 같은 날 종가→종가.
- 판정 창: 워밍업 60세션 뒤 ~ **2026-06-30**. 홀드아웃(2026-07-01~) 안 연다.
- 대리와 실제(완충 구간·risk_parity 비중)의 차이: 대리가 회전이 많다. 오버레이는 수익률 시계열 위의
  연산이라 결론의 방향은 옮겨 가지만, 채택은 **모의계좌 파일럿**을 거친다(아래).

## 오버레이 (고정)

| 변형 | 규칙 |
|---|---|
| BASE | 대리 그대로 |
| H50 | 지수 숏 오버레이. 헤지비 = 0.5 × β₆₀ (직전 60세션 OLS, 미래 안 봄). 캐리 1%/년 × 헤지비 + 헤지비 변화분 편도 0.1% |
| H100 | 위와 같고 1.0 × β₆₀ |
| V15 | 변동성 타기팅. scale = min(1, 15% / σ₂₀), σ₂₀ = 직전 20세션 EWMA 연율 변동성. 레버리지 없음(줄이기만), 현금 수익 0 |
| HV | H50 뒤 V15 |

헤지 수단은 측정에선 지수(선물/인버스 ETF 의 −1× 근사), 실운용은 KODEX 인버스로 바꾸되 그건 배선 단계의 일.

## 지표·판정 (고정)

지표: 연수익 · 연변동성 · Sharpe(rf 0) · MDD · 실현 β · KOSPI200 대비 IR(초과수익 평균/추적오차). 전·후반 반씩 따로.
**파일럿 채택 기준** (변형별): ① Sharpe ≥ BASE + 0.2, ② MDD 가 BASE 대비 20% 이상 얕음, ③ 전·후반 둘 다 Sharpe 가
BASE 이상. 셋 다 → 그 변형을 **모의계좌 파일럿 후보**로 적는다(배선은 별도, 60거래일 종료 기준에서 같이 판정).
하나라도 미달이면 기록만. 변형 넷 중 가장 좋은 것을 고르는 건 허용(등록된 묶음 안), 파라미터 재조정은 불허.
함정: 2025H2~2026H1 은 강세장이라 헤지가 수익을 깎는 게 정상이다 — 그래서 기준이 수익이 아니라 Sharpe·MDD 다.
