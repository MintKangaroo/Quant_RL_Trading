# 시행 X — 공시 원문 임베딩: 제목이 아니라 본문을 읽으면 무너질 종목이 보이나 (사전등록 초안 2026-09-18)

**초안이다.** 설계의 뼈대와 판정 기준은 지금 고정하되, **모델 하나는 측정 전에 따로 고정한다**
(아래 "모델 선정" — 지금 고르면 원문을 보고 고르게 된다). 재료 후보 대장 #6 (2026-09-08 사용자 승인,
"준비되면").

## 왜 이것인가

- 수익 분해의 선택 항이 −3.67%p 로 가장 크다. 문제는 집행이 아니라 **무엇을 고르느냐**다(미체결 종목은
  오히려 더 떨어졌다, 2026-09-18).
- 2c 의 발견: 알파의 대부분이 **하위 십분위(무너질 종목)** 에 있다. 6차 G2 는 공시의 **건수**(부실·희석)를
  센다. 건수는 "무슨 일이 있었나" 는 말하지만 "얼마나 나쁜가" 는 못 말한다 — 같은 유상증자라도 규모와
  목적이 다르다. **본문이 그 차이를 들고 있다.**
- 지금 창고의 `documents` 는 **제목만** 있었다. 원문 수집기(2026-09-12)가 본문을 채우고 있다.

## 선행 조건 — 둘 다 아직이다

1. **원문 완비.** 2026-09-18 기준 5,292건 / 대상 ~70,000건. 하루 3,000건(01:20 크론, 원문 없는 것은
   표식으로 건너뜀) → **10월 중순 완비** 예상. 판정 창(~2026-06-30) 전체를 덮어야 잰다.
2. **한국어 모델.** **캐시된 `ProsusAI/finbert` 는 영어 전용이라 못 쓴다** — DART 원문은 한국어다
   (영문 계약명이 섞일 뿐). `transformers` 도 아직 설치되지 않았다(`torch` 만 있다).

## 모델 선정 — 측정 **전에** 따로 고정한다

지금 고르지 않는 이유: 원문을 보며 모델을 고르면 그 원문에 잘 맞는 모델을 고르게 된다. 선정 기준만
지금 박는다.

- 한국어 문장 임베딩을 공개 가중치로 내는 모델, 로컬 CPU 에서 7만 건을 하룻밤 안에 돈다.
- **판정 창의 원문으로 튜닝하지 않는다**(사전학습 가중치 그대로). 튜닝하면 판정 창을 본 것이다.
- 후보를 둘 이상 두고 **판정 창 밖(2024년 이전) 원문**으로만 품질을 비교해 하나를 고른다.
- 고른 모델의 이름·버전·해시를 이 문서에 적은 뒤에야 측정한다.

## 무엇을 재나

- 세션 s, 종목 i 에 대해 **s 개장 전까지 알 수 있었던**(`observed_at`) 최근 60세션 공시 본문을 임베딩해
  평균한다. 없으면 결측.
- 임베딩(수백 차원)을 **판정 창 밖 원문으로 적합한 PCA** 로 k=3 차원으로 줄인다. PCA 를 판정 창에서
  적합하면 판정 창을 본 것이다.
- 그 3 개를 랭커 피처로 넣는다 — 6차와 같은 방식(묶음 하나, 3 피처, 한 번에 넣고 뺀다).

## 판정 — 6차와 같은 형식, 2026-09-18 교훈 적용

주 시장 = **국장**(DART 원문), 다른 시장 = 미장(원문 없음 → 0, 지지 않을 것만 본다).

| | 기준 | 값 |
|---|---|---|
| ① | 주 시장 ΔIC(h5) NW t(lag 4) | **≥ 2.0** |
| ② | 주 시장 상위 24 h5 z-수익 | 처리 ≥ 대조 **− 0.01** |
| ③ | 주 시장 최악 20세션 블록 ΔIC | ≥ **−0.03** |
| ④ | 다른 시장 ΔIC(h5) | ≥ **−0.005** |

함께 적되 기준 아님: **하위 십분위 z-수익**(처리 ≤ 대조 인지 — "무너질 종목" 가설의 직접 확인).

대조는 그 시점의 실전 랭커 입력(6차·시행 W 에서 채택된 것 누적)이다.
