## 설계 (§3.2)

- **점수 = s_GBM + h_θ(FA).** s_GBM = 대조군 C1(GBM·FA)의 워크포워드 예측을 **얼린 것**(kit 캐시, D1 시드 s ↔ C1 시드 s).
  h = 잔차 머리 FA → 16 → 1(GELU · dropout 0.2 · wd 1e-4 · 묶음 드롭아웃 0.15 · 입력 잡음 0.10, 파라미터 약 1.2천), **마지막 층 0 초기화** —
  학습 전 D1 은 정확히 C1 이다. 그래서 **D1 − C1 이 정확히 "DFL 이 더한 몫"** 이다(§3.1 b).
- **백본 예측은 판정 블록 행에만 있다**(워크포워드). D1 의 학습 자료는 앞 블록들의 C1 표본 밖 예측이고, **첫 판정 블록 = 10**(200세션이 쌓인 뒤).
  대조군도 같은 구간으로 잘라 잰다. 이 값은 자료가 정한다(판정 성적과 무관).
- **소프트 층(학습 전용)** — 입력은 판정 규칙과 **같은 선정 점수**(EMA5, 미장은 AT M1 합성 뒤 EMA5)의 미분판(미장 M1 의 순위 백분위 → Φ(표준화 점수)).
  - **D1a**: 소프트 상위-k(k = 24, σ 문턱 + 뉴턴 한 걸음 암묵 미분) → 동일가중. 국장은 거래가능 명단 안.
  - **D1b**: w ∝ 지수 원 비중 × exp(λ·rank-gauss(선정 점수)), **λ = 0.5**(AX 채택 X3 과 같다 — 리드 승인 2026-09-28), 상한 국장 30%·미장 10% 반복 투영.
    학습에선 rank-gauss 를 부드러운 순위(τ = 0.05σ)로 바꾼다(하드와 상관 > 0.99, 테스트).
- **경로(§3.1 d)** — 같은 위상 10세션 간격의 결정 6개를 **순서대로** 굴린다(첫 1개는 보유를 세우는 워밍업). 비용 항의 직전 보유는
  **하드 규칙이 그 점수로 실제로 든 보유**(완충 3N 포함 · 드리프트 · 기울기 멈춤)다 — 판정 장부와 같은 경로(테스트가 kit 포트와 일수익 대조).
- **손실** = α·L_pred/ℓ_pred + (1−α)·L_port/ℓ_port. L_pred = 세션 안 rank-gauss y5 MSE. L_port = −평균(R) + η·분산(R),
  R = w_soft·G − 편도 비용 × Σ\|w_soft − w_hard,prev,drift\|(D1b 는 B0 대비 초과 — 판정이 지수 대비 IR). G = 10세션 보유 수익(드리프트 포함 정확히 선형).
  ℓ = **첫 학습창에서 h = 0 으로 잰 초기값**(ℓ_pred = 평균 MSE, ℓ_port = R 의 표준편차), 시드마다 얼린다(§3.1 e).
- **판정(§3.1 c)** — D1a: D1 점수를 C1 과 **같은 하드 규칙 포트**(`kit.evaluate_all`: EMA5 · 상위 24 · 완충 72 · C10 · 미장 M1)에 넣는다 = 차이는 점수뿐.
  D1b: 같은 기울이기 규칙의 하드 장부(정확한 rank-gauss). 조기 종료 지표도 **하드 규칙 포트의 내부 검증 연수익**.

## 표본 규율 (§2.2 를 코드로)

1. 블록 = kit(`blocks`), 판정 행 = `block_span` 반열림. 학습 끝점 = `d1_train_end`(간격 16), 그리고 결정마다 **라벨의 마지막 가격일 < 판정 첫 세션**.
2. 내부 검증 = `kit.inner_split(…, purge=16)`(마지막 20%), 적합 결정의 라벨 끝 < 검증 첫 날. 조기 종료는 하드 규칙 포트의 내부 검증 연수익으로만,
   비교 대상에 **h = 0(백본 그대로)** 이 들어간다. 그리고 **채택 여백**(아래 규칙)을 넘어야 머리를 쓴다 — 못 넘으면 C1 이 그대로 남는다.
   기록은 "머리 채택 N/M (조기 종료가 고른 개선 K · 여백 …)".
3. **위상 10벌**로 학습(사슬 시작점이 모든 날), **판정은 위상 0**(kit 규칙 포트). 나머지 위상의 흩어짐은 기록만(이 파일의 장부 — kit 과 일수익 일치 테스트).
4. 국장+미장 합동, 사슬·표준화·순위·라벨은 시장 안에서만. 미장은 미장 달력(국장 휴장일 행 포함, 테스트).
5. 학습 구간은 채점하지 않는다. 학습창 대비 판정창 격차는 과적합 **기록**.
6. 온도·척도는 시드마다 **첫 재학습의 적합 결정**으로만 정한다.

## 채택 여백 (규칙 — 2026-09-28 리드 결정)

합성 shuffle 점검에서 섞은 라벨로도 조기 종료가 머리를 고른 것이 10회 중 5회였다 — 라벨이 잡음이어도 조기 종료가 내부 검증 창의 잡음을 줍는다.
그래서 **머리는 내부 검증 이득 > 채택 여백일 때만 쓴다**(못 넘으면 h = 0 = C1 그대로).

- **이득** = 최고 에포크의 하드 규칙 포트 내부 검증 연수익 − h = 0 의 그것(≥ 0).
- **여백** = **실자료 라벨 섞기**(`shuffle --i-registered`)에서 변형마다 **하나** — 시드 0~4 전체 · 재학습 전체 이득의 **최댓값**(합동).
  시드별 최댓값은 표본 2개짜리라 여백 자체가 잡음이었다(합성: 시드별 0~10.4%).
- 실자료 라벨 섞기: 학습 라벨(수익·y5)을 세션 안에서 섞고 **판정과 같은 재학습**(같은 고정값·같은 학습 끝점)을 돌린다. 내부 검증은 학습 창 안이고
  **진짜 수익**으로 잰다 — 섞은 라벨로 배운 머리가 우연히 얻는 이득의 크기다. 판정 블록 예측을 하나도 만들지 않는다(`gains_only`) — **판정 블록 수익을
  보지 않으므로** canary 와 같은 지위다.
- 얼린 값은 `data/_diag/final-round/D1/shuffle-margin.json`(변형별 여백 · 이득 전부 · 등록 해시 · 백본 · 시드). 판정·canary 는 **읽기만** 하고,
  없거나 해시·백본·시드가 안 맞으면 rc 7. (변형·시드)마다 조각을 남겨 중간에 내려가도 잇는다.
- 변형마다 따로인 이유: 내부 검증 장부가 다르다(D1a 규칙 상위 24 · D1b 지수 기울이기) — 기울이기 장부는 변동이 작아 이득도 작다. 한 값으로 묶으면
  D1a 의 여백이 D1b 를 통째로 막는다.
- `canary`(합성)는 D1a 여백을 **건 채로** 돈다 — 여백이 심은 신호까지 막으면 멈춘다(여백이 너무 큰지의 점검).
- 합성 값(2026-09-28, D1a 합동 최댓값 10.44%)은 **테스트 픽스처로만** 남긴다(`tests/tools/fixtures/dfl-shuffle-margin-synthetic.json`).

## 자기 점검 (판정 전 — 합성 자료, 러너가 둘 다 통과해야 판정을 시작한다)

- `canary` — 합성 자료에 **심은 신호**: 백본(f0)이 상위 8% 로 꼽는 종목 안에서만 수익을 가르고 나머지에선 반대 부호로 상쇄한 f_top(전 종목 IC ~0).
  백본은 f_top 을 안 쓴다. **통과 = D1a − C1 ≥ 1%p**(⑥의 문턱) — 배관이 "IC 로는 안 보이고 포트에만 보이는 신호" 를 찾는다.
- `shuffle` — 학습 라벨(수익·y5)을 세션 안에서 섞는다(피처·백본·판정 장부는 그대로). **통과 = |D1a − C1| ≤ 2%p**(①의 문턱) — 넘으면 라벨이 아닌 길로 정보가 샌다.
- 합성 점검은 **등록 값 그대로**(첫 판정 블록만 합성 창 길이에 맞춰 6), 시드 5. 러너 순서: **실자료 shuffle(여백을 얼린다) → canary(합성, 여백을 건다) → 판정**.
  합성 라벨 섞기(`shuffle --synthetic`, |D1 − C1| ≤ 2%p)는 누설 점검 도구로 남긴다(2026-09-28: +0.4%p 통과).

## 대조와 판정

대조군은 kit 캐시를 **읽기만** 한다(`require_controls`, rc 3) — 모두 **D1 첫 판정 블록부터로 잘라** 잰다.

- **D1a**: `kit.judge(D1a, C0, C1)` — 셋 다 kit 규칙 포트. D1a − C1 = DFL 의 몫.
- **D1b**: `kit.judge(D1b, T0, T1)` — T0·T1 = C0·C1 점수를 **같은 기울이기 장부**에 넣은 것(= 현행 v2 L1 규칙). 규칙 상위 24(C0·C1)와 견주면
  구성 차이가 섞인다(복기 규칙 9). D1b − T1 = DFL 의 몫. C0·C1 규칙 포트·B0 대비는 기록.

### 채택 기준 — 변형마다

① 시드 평균 연수익 ≥ 대조0 + 2%p ② 시드의 80% 이상이 대조0 보다 높다 ③ 두 국면(박스 ~2024-12 · 급등 2025-01~) 모두 ≥ 대조0 − 1%p
④ ΔIC(h5) ≥ 0 ⑤ MDD 가 2%p 넘게 깊지 않고 회전 ≤ 대조0 × 1.2. **DFL 주장**은 ⑥ ≥ 대조1 + 1%p.
(대조0·대조1 = D1a 는 C0·C1, D1b 는 T0·T1.) ⑥ 없이 ①~⑤ 만이면 "정보가 늘어서" 이고 대조1 을 채택 후보로 적는다.

**D1b 는 v2 기준을 더한다**: ⑦ 지수 대비 IR ≥ 0.30 ⑧ 두 국면 지수 대비 초과 ≥ 0 ⑨ 신호 없는 같은 구성 B0(λ = 0) 대비 연수익 ≥ 0. ①~⑨ 모두면 채택.

채택은 **후보**일 뿐 — 11/23 금고(2026-07~11-13)에서 얼린 머리로 한 번 더(규율 16).

### 성향 점검 (규율 15 — 채택 전 필수 기록)

β · 박스/급등 β(대 백본 β), 재조정일 비중으로 가중한 성향 노출(원피처 `raw_regime_beta`·`raw_fundamental_book_to_market`·`raw_event_dividend`) 대 백본.
η·분산 항은 저β 쪽으로 미는 힘이 있다 — 이득이 β 로 설명되면 채택하지 않고 적는다.

## FA+ (§3.3 — 조건부 절)

`--backbone C2 --features FA+`: **C2(GBM·FA+)가 C1 을 이긴 경우에만** D1 을 FA+ 위에서 한 번 더 잰다(같은 고정값·같은 기준, 대조 C0·C2).
짝이 다르면 거부, C2 캐시·FA+ 묶음(kit 의 G10~G13 정의)이 없으면 rc 3. 이 절은 사후 선택이 아니다 — 조건을 지금 적는다.

## 명세에서 벗어난 것 — 해시 고정 전에 적는다

- **D1b 의 L_port 는 B0 대비 초과**의 평균·분산(§3.2 는 "포트 수익"). 판정이 지수 대비 IR 이라서(규율 2). 수익 항의 기울기는 같고 분산 항만 추적오차.
- **D1b 의 판정 대조는 T0·T1**(같은 기울이기 장부) · L_port = B0 대비 초과 · λ = 0.5 — 리드 승인 2026-09-28(§3.2 는 리드가 고친다).
- 미장 M1 의 순위 백분위는 학습에서 Φ(표준화 점수)로, D1b 의 rank-gauss 는 부드러운 순위로 근사한다(하드 경로는 정확한 순위).
- 선정 점수 EMA 를 20세션에서 자른다(잘린 가중치 합 0.03%).
- **판정 창 41 → 31 블록**(첫 판정 블록 10) — 백본(C1) 예측은 판정 블록 행에만 있어(워크포워드) 앞 10블록(200세션)은 머리의 학습 자료다.
  모든 군(D1·C0·C1·T0·T1·B0)을 같은 구간으로 잘라 채점한다. 수치(국장 축, `kit.blocks`, 달력 `data/_diag/kr-long/calendar-KR.pkl` — 수익은 안 봤다):

  | | 블록 | 채점 세션(국장 축) | 기간 | 박스(~2024-12) | 급등(2025-01~) |
  |---|---|---|---|---|---|
  | 공통 틀 | 41 | 820 | 2023-02-15 ~ 2026-06-29 | 459 | 361 |
  | D1 | 31 | 620 | 2023-12-07 ~ 2026-06-29 | 259 | 361 |

  **최소 검출 효과 재계산** — 연수익 차이의 MDE = (1.96 + 0.84) × TE / √(세션/252)(양측 5% · 검정력 80%, TE = D1 − 대조 일수익 차이의 연 추적오차):

  | 구간 | 공통 틀 | D1 | 배수 | TE 3% 일 때 | TE 5% 일 때 |
  |---|---|---|---|---|---|
  | 전체 | 1.55·TE | 1.79·TE | ×1.15 | 4.7 → 5.4%p | 7.8 → 8.9%p |
  | 박스 | 2.07·TE | 2.76·TE | ×1.33 | 6.2 → 8.3%p | 10.4 → 13.8%p |
  | 급등 | 2.34·TE | 2.34·TE | ×1.00 | 7.0%p | 11.7%p |

  TE 는 판정 전이라 모른다(머리가 작고 0 에서 시작하므로 C1 대비 TE 는 작을 것이다 — 판정 때 실측해 기록한다). **읽는 법**: 기준 ①(+2%p)·⑥(+1%p)은
  유의성 검정이 아니라 **결정 규칙**이다 — TE 3% 에서도 MDE 5.4%p 라 이 창 하나로는 2%p 차이를 통계적으로 가를 수 없다. 박스 국면 다리(③)는 표본이 44% 줄어
  가장 약하다. 그래서 채택은 후보일 뿐이고 금고(11/23, 약 95세션)가 따로 심판한다(규율 16). 이 축소는 자료 구조가 정한 것이다(판정 성적과 무관).
- 비용의 출처: 국장 0.41% 는 store.config 에 없다 — kit 이 `trial_overlay.ONE_WAY_COST` 를 쓴다(config 로 옮기는 것은 kit 쪽 일 — 리드 요청).

## 알려진 틈 (해시 고정 전에 적는다)

- **국장 편도 비용 0.41% 가 store.config 에 없다**(불변식 10) — kit 이 `trial_overlay.ONE_WAY_COST` 상수를 쓰고, D1 은 대조군과 같은 값을 쓰려고
  `MarketBook.cost` 를 읽는다. config 이전은 옳지만 기존 시행 지문과 얽혀 있어 **최종 회차(BE·BF·BG) 뒤 별도 커밋**으로 한다(리드 결정 2026-09-28).
  이 시행의 판정은 0.41% 로 고정된다 — 이전 뒤에도 값이 같으면 결과가 바뀌지 않는다.
- **FA+ 묶음(G8·G10~G13)** 은 kit 에 아직 없다 — BE·BF·BG 가 끝난 뒤 리드가 넣는다. 그때까지 `--features FA+` 는 rc 3.
- **채택 여백은 실자료 라벨 섞기로 얼린다**(리드 결정 2026-09-28) — 합성 여백은 실자료 검증 잡음의 크기를 말해 주지 않는다. 대가는 계산량(판정만큼의 재학습이
  한 번 더)이고, 여백은 변형마다 합동 최댓값 하나라 보수적이다(머리가 채택되기 어렵다 — 채택되면 그만큼 강한 증거). 판정 때 실자료 이득 분포를 여백과 나란히 기록한다.

## 한계

- 판정 창을 수십 번 쓴 뒤의 시행이다 — 채택돼도 금고 심사 전에는 실전에 넣지 않는다.
- 판정 창이 41블록에서 31블록(820 → 620세션, 박스 459 → 259)으로 준다 — 수치와 MDE 는 '명세에서 벗어난 것' 절.
- 소프트 상위-k 의 그래디언트는 경계 근처 종목에만 간다 — 맨 위 순서는 L_pred 만 가르친다. 하드 규칙의 완충은 소프트 층에 없다(직전 보유로만 들어온다).
- 머리가 작고 0 에서 시작하므로 D1 은 C1 에서 멀리 못 간다 — 겹침이 높고 차이가 작게 나올 수 있다. 그것이 설계의 의도(외우지 못하게)이자 한계다.
- D1b 의 국장 유동비율은 현재값 하나다(AZ 와 같은 한계).
