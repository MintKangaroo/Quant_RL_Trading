## 왜 — 그리고 X 와 무엇이 다른가

마지막 회차·BE3 결론: 점수 쓰는 법·학습 기법으로는 C1 을 못 넘었다. 병목은 정보다. BA(9/27 기각)는 공시 **개수**가 스타일 노출일 뿐임을
보였다. TX 는 공시 **내용**을 읽는다.

**이 원천은 이미 한 번 졌다(시행 X).** X 는 e5-small 로 원문 **앞 512 토큰**을 임베딩해 **창 밖 PCA 3축**을 넣었고, ΔIC −0.0015 · 상위 24 세 시드
모두 −0.02 였다. X 문서의 읽는 법: PCA 축은 **공시 유형**(계약·자사주·실적·분할·희석)을 가르는 축이었고 유형은 event 가 이미 쓴다.
"좋은 소식인가" 를 담으려면 수익과 이어진 표현이 필요한데, X 는 판정 창을 볼까 봐 일부러 하지 않았다. 그때는 원문이 2025-02 이후뿐이어서
**판정 창 이전에 수익으로 적합할 자료가 없었다.**

인코더는 수익을 내지 않지만, 사전학습 말뭉치에 "그 회사가 뒤에 어떻게 됐나"(2023~ 뉴스)가 있으면 같은 회사·같은 문맥의 벡터가 미래를 품을 수 있다.
판정 창 첫 채점 세션은 **2023-02-15**(학습 끝점 2023-01-31, `kit.train_end`).

- A·C: 말뭉치가 확장 패널 시작(2021-08) 이전이다 — **판정 창의 어떤 사건도 볼 수 없었다.** B: 판정 창 앞 약 4개월(41블록 중 4~5블록)이 말뭉치 시점과 겹칠 수 있다.
- **권고: A(ko-sroberta).** 속도가 B 의 0.43배지만 수시공시 전부가 두 밤이면 끝난다(아래 일정). 누수 반론을 처음부터 지우는 값이 더 크다.
- 완화책(인코더와 무관하게 전부 적용):
  1. **회사명·종목코드 가림** — `documents.filer` 와 6자리 코드를 `[회사]` 로 바꾼 뒤 임베딩. 회사 이름에 붙은 사후 지식 통로를 막는다.
  2. **지도 머리는 2023-01-31 에 얼린다** — 판정 창 수익으로 적합하지 않는다.
  3. **금고 확정** — 금고 창(2026-07~)은 세 후보 모두의 말뭉치보다 뒤다. 판정 창 결과는 1차, 채택은 금고가 정한다.

## 피처 정의 (묶음 TX, 3개 + 결측 표지 1 — 6차 규약)

모든 피처는 국장만. 미장은 결측(kit 규칙대로 rank-gauss 0 + 표지 1).

### 공통 — 수시공시 문서 벡터

1. 대상: 수집 유형의 **수시공시**(정기보고서 제외). 정정 공시는 별개 문서로 자기 접수일에 들어간다(원공시를 덮지 않는다).
2. 정제: 머리말 줄(귀중·제출일·회사명·대표이사·본점·전화·홈페이지·작성책임자) 제거 → 회사명·종목코드 가림 → 공백 정규화.
3. 512 토큰 조각(겹침 없음) **앞에서 최대 4개**, 조각 벡터를 토큰 수로 가중 평균 → L2 정규화. 평균 조각 수 2.2(2025 표본 600건 실측).
4. **유형 중심 빼기**: `doc_type` × 정규화 제목(상위 30종, 나머지는 유형 공통)의 평균 벡터를 **2023-01-31 이전 문서로만** 구해 뺀다. X 가 잡은 "유형 축" 을 지운다.

### tx 머리 — 얼린 리지

- 라벨: 문서가 처음 보이는 세션 s_d(아래 observed_at 규칙)의 kit 타깃 **y5 rank-gauss**(시행 L·회차와 같은 타깃).
- 적합: 라벨 창이 **2023-01-31 이전에 닫힌** 문서만(약 3.8만 건 추정). 표준화 + 리지. 알파는 {10, 100, 1,000, 10,000} 중 **적합 구간 안의
  시간순 5겹(퍼지 5세션)** IC 로 고른다 — 판정 창은 보지 않는다. 고른 알파·계수 해시를 이 문서에 적고 얼린다.
- **적합 구간 문서의 점수는 시간순 5겹 OOF 예측**이다(제 라벨로 적합한 점수를 GBM 에 주면 학습 행에서만 강해 보인다). 2023-02 이후 문서는 얼린 모델의 점수.
  이 점수는 kit 의 GBM 이 첫 재학습부터 보는 정적 피처라, 회차의 월 조각 캐시 방식(`data/_diag/ranker-sources/TX-KR-<연월>.parquet`)에 그대로 들어간다.

  계수 파일 머리에 적고, 판정 도구가 그 날짜를 검사한다.
- `tx_change` 의 observed_at = 나중 보고서의 접수일 다음 날 08:00.
- 첫 측정 전 **스모크**: 국장 판정 창 첫 30세션에 TX 행이 몇 % 붙는지 먼저 찍는다(X 의 0행 사고 재발 방지). 0 이면 판정하지 않는다.

## 대조 · 판정 — 회차 kit 그대로

자료·블록·포트·비용·시드 5·퍼지+엠바고는 `final-model-round-2026-10.md` 공통 틀과 같다(판정 창 2022-07~2026-06, 첫 채점 2023-02-15).

- **처리 T** = 회차 GBM 을 **FA + TX(3 + 표지 1 = 80열)** 로. 하이퍼파라미터는 C1 과 같다.
- **대조**: C0(6점수) · **C1(GBM·FA)** — 회차 캐시를 읽기만(`require_controls`, 없으면 rc 3).
- **앙상블 대조**: **BE2** = rank_average(BE1_s, C1_s)(회차 캐시) vs **BE2-TX** = rank_average(BE1_s, T_s). BE1 은 다시 학습하지 않는다.

채택 기준(정보 주장 — TX 는 새 정보원이다, 규칙 ⑦):

| | 기준 |
|---|---|
| ① | T 시드 평균 연수익 ≥ **C1 + 1%p** |
| ② | 같은 시드끼리 T > C1 이 5 중 **4 이상** |
| ③ | 두 국면(박스 ~2024-12 · 급등 2025-01~) 모두 T ≥ C1 − 1%p |
| ④ | 국장 ΔIC(h5, T − C1) ≥ 0 · NW t(lag 4) ≥ 2.0 |
| ⑤ | MDD 가 C1 보다 2%p 넘게 깊지 않고 회전 ≤ C1 × 1.2 |
| ⑥ | 미장(TX 결측) 연수익 ≥ C1 − 0.5%p (지지 않을 것만) |
| ⑦ | (앙상블 주장) BE2-TX 시드 평균 ≥ BE2 + 1%p · 5 중 4 이상 |

판정: ①~⑥ → **채택 후보 T(C1+TX)** · 추가로 ⑦ → **BE2-TX 가 BE2 를 대체할 후보** · 그 밖 → **기각**(같은 인코더·같은 머리로 기준을 바꿔 다시 등록하지 않는다).

함께 적되 기준 아님: 하위 십분위 z-수익(T ≤ C1 인가), 피처 gain 몫, tx_tone IC 의 OOF·판정 창·금고 비교(누수 탐지), 세 피처 각각을 뺀 기여(측정 뒤 기록만).

**금고 확정.** 채택은 후보다. 금고 창 early(7/1~9/30)는 10/13 BE2 등에 이미 열린다 — TX 는 그 창을 쓸 수 없다. 후보:
`second`(10/1~11/13, 11/23 판정, 국장 약 30세션 — 짧다) 에 **얼린 T 를 등록해 함께 연다** 또는 그 뒤 전방 창. 사용자 결정 4.

### 다중검정 기록

- `research_trials` 에 family `sources`, 시행 TX 1행(protocol_hash). **같은 원천의 두 번째 시행**(X 다음)임을 행에 적는다 — DSR 의 시행 수에 X 를 함께 센다.
