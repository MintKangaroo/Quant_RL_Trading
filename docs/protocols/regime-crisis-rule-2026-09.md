# 사전등록 초안 — 국면 crisis 조건: 부호 하나가 노출 절반을 가르는 규칙 (2026-09-07 등록 · family `exposure` · 1회 · 사용자 "네 판단대로" — 등록을 권했고 승인)

측정 전에 고정한다. 결과를 보고 기준을 바꾸지 않는다 (self-improvement.md §1②).

## 계기 (사실)

2026-09-04 저녁 shadow 판단이 국면을 **crisis** 로 읽어 노출 배수를 0.5 로 내렸고(전날 0.8), 9/7 세션이 매도 33건을 내
익스포저가 37% 가 됐다. 판정 근거(`analysts/regime.py`): 대용 지수 **KRX 300**(코스피가 창고에 없던 때의 선택)의
60일 실현변동성이 자기 400일 분포의 75% 분위 위, **21세션 모멘텀 −0.6%**. 규칙은 "변동성 높음 + 모멘텀 < 0 → crisis(×0.5)",
"모멘텀 ≥ 0 → volatile(×1.0)" 이라 부호 하나에 노출이 절반 갈린다. 같은 날 KOSPI(이제 창고에 531세션 있음)의 21세션 모멘텀은
+1.35% 였다. 8/22~27 에도 crisis↔volatile 이 하루걸러 뒤집혀 왕복 매매를 했고, 그때 넣은 것이 `regime_confirm_sessions: 2`
(올릴 때만 2세션 확인)다 — 내리는 쪽의 민감함은 그대로다.

## 가설과 변형 (한 묶음, 측정 전 고정)

| 변형 | 규칙 | 뜻 |
|---|---|---|
| R0 현행 | 대용 KRX 300 · crisis = 고변동 ∧ 모멘텀 < 0 | 대조 |
| R1 폭 기준 | crisis = 고변동 ∧ 모멘텀 < **−3%** (−3%~0 은 volatile) | "살짝 음수" 를 위기로 읽지 않는다 |
| R2 대용 교체 | 대용 = **KR:IDX:KOSPI**, 규칙은 현행 | 시장 대용치를 시장 그 자체로 |
| R3 | R1 + R2 | 둘 다 |

−3% 는 측정 전에 정한 값이다(21세션 = 한 달, 한 달 −3% 아래를 "떨어지고 있다" 로 본다). 격자로 고르지 않는다 —
격자에서 최고를 고르면 그 표본의 잡음을 산다(alpha-decay-breadth §2 의 교훈).
바꾸지 않는 것: 변동성 분위(75%), bear 0.7 · crisis 0.5 · squeeze 0.8 · below_trend 0.6 배수, 확인 2세션, 나머지 전부.

## 측정 (고정)

- 전략 대리: 5회차 대조 경로(`trial_alpha_breadth.path`, ranker·EMA5·완충 72·동일가중 N=24)의 **비용 후** 일수익 r_t.
  노출을 씌운 수익 = scale_t × r_t − 배수 변화 비용(|Δscale| × 편도 0.41%), scale_t 는 세션 t 전날 종가까지로 정한다. 현금 수익 0.
  **국면 배수만** 잰다 — 추세(200일선)·압축 배수는 네 변형에 똑같이 걸리므로 차이에 기여하지 않는다(min 결합이라 완전히 같진
  않다는 것을 안다; 그 차이는 채택 뒤 shadow 에서 본다).
- scale_t 는 변형별 규칙으로 **as_of 시점 자료만**으로 계산(regime.state 와 같은 창: 400일 분포, 60일 변동성, 21세션
  모멘텀, 확인 2세션). 대용 지수 두 개 다 `indices` 표(KRX Open API, 2024-07-01~).
- 판정 창: 2025-01-02 ~ **2026-06-30**(홀드아웃 안 연다). 2026-09-04 사건 자체는 판정 창 밖이다 — 계기일 뿐 근거가 아니다.
- **채택 기준(먼저 고정)** — R1·R2·R3 각각 R0 대비: ① 비용 후 연수익 ≥ R0 ② MDD ≤ R0(더 나쁘지 않을 것) ③ 배수 전환 횟수 ≤ R0.
  셋 다 통과한 변형이 여럿이면 **단순한 쪽**(R1 또는 R2)을 택하고 R3 는 둘 다 각각 통과했을 때만. 하나도 없으면 기각, 현행 유지.
- 함께 적되 기준 아님: crisis 세션 수, 왕복(0.5→1.0→0.5) 횟수, 판정 창 전반/후반 분할.

## 채택 시

- R1: `exposure.crisis_momentum_floor: -0.03` 신설(config, 불변식 10) + `regime.state` 분기. R2: `MARKET_PROXIES` 첫 항목을
  `KR:IDX:KOSPI` 로(코드 상수 — 대용치 선택은 설정이 아니라 설계다).
- 실운용 반영은 채택 다음 세션부터. **지금 포지션에 소급하지 않는다** — 9/4 판정으로 줄인 노출은 규칙이 스스로 되돌린다
  (모멘텀이 양수로 돌아오면 volatile, 확인 2세션 뒤 1.0).

## 하지 않는 것

−3% 를 격자로 고르는 것, 배수 값 변경, 판정 창을 2026-09 사건이 들어오게 옮기는 것, 홀드아웃 개봉.
