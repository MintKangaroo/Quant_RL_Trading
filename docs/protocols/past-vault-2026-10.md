# 사전등록 — 과거 금고: 국장 2010-01 ~ 2021-07 (가격 기반 후보 셋 · 10/13 한 번 개봉)

## 왜

10/13 금고(7/1~9/30)는 62세션이라 포트 기준으로는 +2%p 차이를 가를 수 없다(`self-improvement.md` §10). KRX Open API 가 2010 년부터 일별 시세·상장주식수·시가총액을
준다는 것을 10/10 확인했다(2010-06-01 1,931종목). 지금 창고는 2021-08 부터라 **2010-01~2021-07 약 2,860세션은 아무도 본 적 없는 구간**이다.
가격만으로 만드는 후보는 이 구간에서 46배 긴 표본으로 판정할 수 있다.

## 범위 — 가격 기반 후보만 (솔직하게)

| 후보 | 과거 금고 | 이유 |
|---|---|---|
| **TF** TTM 하위 20% 빼기 | ○ | TTM 은 가격만 본다. 단 TTM 공개(2024-10) 전 구간이라 사전학습 누수 가능 — 고정본 규칙 6(누수 낮음)을 따르되 **한계에 적는다** |
| **TB** TF + TTM 상위 10% 빼기 | ○ | 같음 |
| **TG** 기술적 합성 하위 20% 빼기 | ○ | 보정 OHLC·거래대금만. 누수 없음(규칙으로 만든 점수) |
| BE2 · AQ · AR · AS · P1-b″ · TC | × | 재무·수급·공시 기반 점수(FA·랭커)를 만들 원재료가 이 구간 창고에 없다 — 10/13 early 금고만으로 판정(원래대로) |

## 자료

- 봉인 창고 `data/_past_vault`(`tools/backfill_past_vault.py`): prices(원주가 OHLCV·거래대금, `adj_factor` = KRX 기준가로 낸 기업행위 배율) · market_stats(상장주식수·시가총액). 상폐 종목 포함(그날 스냅샷).
- 결정 세션: **2011-01-03 ~ 2021-07-30**(첫 해는 252세션 이력용). 마지막 결정은 5세션 라벨이 2021-08-10 안에 닫히는 날.
- 점수: TG = `tools/ta_composite.composite_panel`(실전·early 와 같은 함수) · TF/TB = TTM r2 제로샷 r̂(t+1→t+6), `tools/vault_tsfm_bake.py` 와 같은 입력 규칙. **하루 늦춤**(결정 d 에 d−1 종가까지의 점수).
- 대상(점수가 있는 종목) = 20일 평균 거래대금 ≥ 10억원 · 이력 252세션. 제외 = 대상 n 중 하위 ⌊0.2n⌋(TB 는 상위 ⌊0.1n⌋ 도).
- 국면 세 구간: A 2011-01~2014-12 · B 2015-01~2018-12 · C 2019-01~2021-07. 2015-06-15 가격제한폭 ±15% → ±30% 는 그대로 둔다(기록).

## 판정 기준 — 후보마다 셋 다

1. **원리**(종목 단위, 주 기준): 결정 세션마다 뺀 종목의 다음 5세션 누적 − 대상 동일가중의 같은 수익. 세션 평균 < 0 **그리고** NW t(lag 4) ≤ **−3.0**(표본이 길어 더 엄격하게).
   세 구간 모두 평균 < 0.
2. **넓은 포트**(해 방지 + 효과): 대상 동일가중 − 제외(5세션 재조정, d+1 종가 진입, 편도 0.41%) 대 대상 동일가중 — 비용 후 연 초과 > 0 · IR ≥ 0.5 · 세 구간 모두 > 0.
3. **대형주**(해 방지): 시가총액 상위 200 시총가중(종목 상한 30%) − 제외 대 같은 200 — 비용 후 연 초과 ≥ 0. IR 은 기록.

셋 다 → **과거 금고 통과**. 하나라도 아니면 기각.

**기록(기준 아님)**: TTM 과 TA 의 겹침(상대 통제 편 IC) · 1차·2차 기술적 지표 개별 IC(시행 TK 의 근거) · 국면별 표.

## 10/13 대격변에서의 쓰임 (결과 전 고정)

- **TF·TB** — 실전 후보 = (early 금고 기준 통과) **또는** (과거 금고 통과 **그리고** early 에서 뒤집히지 않음: 원리 평균 < 0 · 시드 평균 포트 ≥ 대조 − 1%p).
- **TG** — 실전 후보 = 과거 금고 통과. 11/23 second 금고(TG 등록 기준)는 **뒤집히면 빼는 확인**으로 쓴다(BE2 와 같은 규칙).
- 두 번째 하한 자리는 하나다: 후보가 둘 이상이면 **과거 금고 원리 t 가 가장 강한(가장 음수) 하나**. TB 는 그 하나가 TF 계열일 때만 상한을 더한다.
- 실제 반영은 10/13 저녁 결과 보고 뒤 사용자 설문.

## 한계

1. 포트는 실전(랭커 상위 24)과 다르다 — 이 구간엔 랭커 점수가 없다. 넓은 포트·대형주 포트는 대리다.
2. TTM 은 2024 공개 모델이다. 사전학습 자료에 이 구간 국장 시세가 들어갔는지 모른다 — TF·TB 의 과거 금고 결과는 TG 보다 약한 증거로 읽는다.
3. 2010~2015 의 시장 구조(가격제한폭 ±15% · 공매도 규제 · 거래대금 수준)가 지금과 다르다. 10억 기준은 명목값이라 앞 구간 대상이 더 좁다.
4. 기업행위 보정은 KRX 기준가에서 낸다 — 기준가가 바뀌지 않는 사건(현금배당 등)은 보정하지 않는다(수익률에 배당락이 남는다, 본 창고와 같은 규칙).
