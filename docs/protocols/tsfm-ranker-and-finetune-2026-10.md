# 사전등록 — 시행 TR(TTM 을 랭커 피처로) · 시행 TT(TTM 국장 미세조정) (family `ranker` · 예산 2 · 국장)

## 왜

TTM r2 제로샷(종가 256일만)의 국장 5일 IC 가 장기(2022-08~2025-02, t 8.2)·최근(2025-03~2026-06) 모두 +0.07~+0.09 로 우리 랭커(0.03~0.09)와 같거나 높다.
지금은 **하한(빼기)** 으로만 쓴다(IX-T 전방, 10/13 금고 TF·TB·TC). 두 질문이 남는다.

1. **TR** — TTM 이 랭커가 이미 아는 것(반전·변동성·수급)과 다른 것을 아는가? 랭커 입력에 넣으면 **상위 N 포트**가 나아지는가.
2. **TT** — 범용 사전학습 모델을 국장 종가로 조금 더 가르치면(머리만) **패자 판별**이 나아지는가.

## 시행 TR — TTM 을 랭커 피처 하나로

- **처리**: 현행 랭커(시행 L 규격: GBM · 잎 7 · rank-gauss h5 타깃) 입력에 **피처 하나** `ttm_pct` = 그 세션 TTM r̂ 의 횡단면 백분위([−1,1]) — **하루 늦춤**(d 결정에 d−1 밤 예측).
  피처를 여럿(원값·분위 표지·변화량)으로 늘리지 않는다(규율 1).
- **C1** = 같은 폴드·같은 시드로 `ttm_pct` 만 뺀 재학습. **C0** = 실전 규칙(기록).
- **채택 기준(넷 다, 9/25 랭커 계열 틀)**:
  1. 시드 평균 비용 후 연수익(상위 24 포트) ≥ C1 + **2%p**
  2. 시드 5 중 **4 이상**이 같은 시드 C1 보다 높다
  3. 두 국면 모두 ≥ C1 − 1%p
  4. 해 방지: 전 종목 h5 IC ≥ C1 − 0.005 · MDD 가 C1 보다 2%p 넘게 깊지 않다 · 연회전 ≤ C1 × 1.3
- **기록(기준 아님)**: 성향 대리(β·크기·변동성 — 규율 15), 피처 중요도 순위, 하위 10분위 초과(패자 판별이 랭커 안에서도 사는지), D₀ 뒤 창 표.
- 통과 = 후보. **11/23 금고에서 얼린 모델로 뒤집히지 않음 확인**(TF 와 같은 꼴: 방향 ≥ C1 · 시드 4/5 · 두 구간 ≥ −1%p) → shadow 20세션 → 사용자 승인.

## 시행 TT — TTM 국장 미세조정(머리만)

- **처리**: TTM r2 몸통 고정, **예측 머리만** 국장 보정 로그종가 창(256 → 6)으로 미세조정. 손실 = TTM 기본(정규화된 미래 경로 MSE).
  하이퍼파라미터 고정: 학습률 1e-3 · 배치 256 · 최대 5 에포크 · 조기 종료는 학습창 마지막 20%(퍼지 5 포함, 규율 8) · 시드 5.
  학습 표본: 학습창 안 **격세션**(짝수 세션) × 그 세션 거래대금 상위 1,000 — 비용을 고정하려는 것이고 판정 창과 무관하게 정한다.
- **워크포워드(연 단위 재학습)**: ≤2023-12 학습 → 2024 예측 · ≤2024-12 → 2025 · ≤2025-12 → 2026-01~06. 퍼지·엠바고 5.
- **C1** = 같은 창·같은 종목의 **제로샷 TTM**(미세조정만 뺀 것). C0 = 실전 규칙(기록).
- **판정 = 쓰는 곳에서**: 지금 TTM 의 쓰임은 패자 빼기다. 그래서 주 기준은 **거래가능 동일가중 − r̂ 하위 20%(하루 늦춤, 5세션 재조정, 비용 후)** 의 연수익.
  1. 시드 평균 ≥ C1(제로샷으로 같은 규칙) + **1%p**
  2. 시드 4/5 가 C1 보다 높다
  3. 두 국면(2024 박스 · 2025~ 급등) 모두 ≥ C1 − 1%p
  4. 해 방지: 5일 IC ≥ C1 − 0.005 · 하위 10분위 5일 초과가 C1 보다 덜 음수가 아니다(패자 판별을 잃지 않는다)
- **기록**: 상위 10분위 초과(칼날이 줄었나), 미장 같은 표(학습은 국장만 — 미장 제로샷 IC ≤0 이 바뀌는지 참고).
- 통과 = 후보. **11/23 금고에서 얼린 머리(시드 5, ≤2025-12 학습 폴드)로 뒤집히지 않음 확인**: second 창에서 같은 주 기준이 ① 시드 평균 ≥ C1 ② 시드 4/5 ③ 창을 반으로 가른 두 구간 모두 ≥ C1 − 1%p.
  통과하면 IX-T 의 신호 교체는 **새 등록**으로(IX-T 등록은 v1/v2 제로샷 고정, 바꾸지 않는다).
