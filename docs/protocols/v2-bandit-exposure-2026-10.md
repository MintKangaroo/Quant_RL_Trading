# 사전등록 **초안 — 사용자 승인 전, 해시 미고정** · 시행 R0: 맥락적 밴딧으로 노출 정하기 (v2 L3 첫 학습)

> 이 문서는 **초안**이다. 사용자 승인 전이고 프로토콜 해시를 고정하지 않았다. 도구(`tools/v2_bandit.py`)의 판정·학습·행동 적기 경로는

>
> 작성 2026-09-27 · 측정 예정 2026-10-05~09(v2 로드맵) · family `selection` · 1회 · 시장 국장

## 왜

`docs/design/ai-architecture-v2.md` §2 L3 · 로드맵 "10/5~9 R0 밴딧 기준선". v2 는 **강화학습을 노출·재조정에만** 둔다 —
거래의 76%가 노출 축에서 났고(`turnover-is-exposure-timing`), 수익 분해의 노출 항이 −3.03~−4.47%p 였다. 배분 RL 은 네 번
천장을 확인했으므로(`docs/rl-postmortem.md`) 하지 않는다.

시행 BB 에서 **비지도 국면 확률(HMM)이 규칙 V6 보다 위험 대비 성과가 나았다**(샤프 1.65 vs 1.53, MDD −19.3% vs −21.9%, 4/4 원천).
다만 그 매핑(0.5/0.8/1.0)은 사람이 V6 에서 옮겨 고정한 것이다. R0 이 묻는 것은 하나다:

> **같은 상태값을 보고 매핑을 사람이 아니라 자료가 정하면 더 나은가.**

여기서 못 이기면 PPO(R1)는 하지 않는다 — 행동이 더 크고 표본은 같은데 밴딧이 못 찾은 것을 신경망이 찾았다면 그건 외운 것이다.

## 고정 — 측정 전에 정한 것

- **판정은 국장만.** 미장은 국면 노출이 두 번(AW·AY) 수익만 깎았다 — 기록만.
- **기본 포트**: 시행 BB 와 **같은 구성** — K0(K200 유동시총 대용, 상한 10%·종목 30%), 점수 원천 넷(실전 랭커 + 루프 GBM 3시드),
  EMA5 평활, **10세션 재조정**(AO C10), 편도 비용 0.41%. 비중 경로는 `tools/v2_sim.py`(실전 보유일 규칙을 공유하는 순수 함수).
- **판정 창** 2023-02-15~2026-06-30(821세션), 국면 둘(박스 ~2024-12 · 급등 2025-01~). **금고(2026-07-01~)는 열지 않는다.**
- **행동** k ∈ {0.50, 0.70, 0.85, 1.00}. v2 가 정한 [0.30, 1] 안이고, BB 의 세 배수(0.5·0.8·1.0)를 덮는다.
  재조정 여부 b 는 **행동에 넣지 않는다**(규칙 10세션).
- **전환 비용을 점수에서 먼저 뺀다.** 팔을 고를 때 `|k_후보 − k_직전| × 편도비용` 을 감한다. 미래 정보가 아니라 이미 정해진
  수수료율이고, 없으면 밴딧은 잡음만큼 매일 노출을 왕복시킨다(합성 스모크에서 연회전 9.3 → 5.3, 전환 횟수도 줄었다).
  이것이 규칙의 데드밴드 자리다 — 팔 간격(0.15~0.20)이 실전 밴드 0.10 보다 커서 밴드로는 아무것도 못 막는다.
- **문맥 8칸** — 전부 그날 개장 전에 알 수 있고 과거 이력이 있다(CLAUDE.md 금지사항):

  | 칸 | 출처 | 고정 스케일 |
  |---|---|---|
  | bias | — | 1 |
  | p0·p1·p2 | U1 HMM 전방 필터 확률(`data/_diag/v2/hmm-KR.pkl`, 월 재적합, 전날까지) | 1 |
  | ret20 | 지수 20세션 수익(전날 종가까지) | ×10 |
  | vol20 | 지수 20세션 실현변동성 | ×5 |
  | index_dd | 지수 낙폭(전고점 대비) | ×5 |
  | prev_k | 직전 노출 행동 | 1 |

  스케일은 **고정 상수**다 — 자료에서 추정한 평균·표준편차를 안 쓰므로 표준화 누수가 없다. 포트폴리오 NAV 낙폭 대신 **지수 낙폭**을
  쓴 이유는 실전에서 같은 코드로 같은 값을 얻어야 하기 때문이다(불변식 5).
- **보상** — `docs/design/reward-and-risk.md` §2 그대로: `r = (r_port,net − r_bench) − w(d)·Δd`, 밴드 12/22/30 · w = 0/1.5/8.0,
  Δd 는 **신저점일 때만** > 0. 비용은 r_port,net 에 이미 들어 있고 다시 빼지 않는다. LLM 출력은 들어가지 않는다(불변식 8).
- **미래를 안 보는 장치**: 시뮬 하루 수익이 t+1→t+2 구간이라, t 의 선택은 **t−2 까지의 보상만** 학습한 모델로 한다(`FEEDBACK_LAG = 2`).
  에폭 없음 — 같은 날을 두 번 배우지 않는다(워크포워드 한 번 통과).
- **알고리즘** LinUCB(주), 선형 톰슨(기록). 상수 α 0.30 · 릿지 1.0 · 보상 스케일 1%p = 1.0 — **자료를 보기 전에** 보상 크기로 정했다.
- **시드 3**(0·1·2). 밴딧 시드는 톰슨의 난수와 보고용 흩어짐에 쓰인다(LinUCB 는 난수가 없어 원천 넷이 흩어짐의 축이다).

## 변형과 대조

| 이름 | 무엇 | 왜 필요한가 |
|---|---|---|
| C0 | 노출 끔(k = 1) | **신호 없는 같은 구성** — 노출 조절 자체가 값을 해야 한다(복기 규칙 9) |
| **C1** | 규칙 V6(실전 현행, 2세션 확인) | 실전 대조 |
| **C2** | HMM 사람 매핑(BB E2, shadow 후보) | "자료가 매핑을 정하면 낫나" 의 직접 대조 |
| **B0** | **문맥 없는** 같은 밴딧(절편만) | 문맥이 값을 하는지 가른다 — B0 이 이기면 "국면 상태값엔 정보가 없다" |
| B1 | LinUCB (주 후보) | |
| B2 | 선형 톰슨 | 기록만 |

## 채택 기준 — 여섯 다 (원천 넷 평균, B1 대 대조)

대조 = `max(C1, C2)` — 현행 규칙과 이미 앞선 HMM 매핑 **둘 다** 넘어야 한다.

① 샤프 ≥ 대조 + 0.10 ② MDD 가 대조보다 1%p 넘게 깊지 않다 ③ 연수익 ≥ 대조 − 1%p ④ **원천 넷 모두** 샤프가 대조보다 높다
⑤ 샤프 ≥ C0(노출 끔) ⑥ **샤프 ≥ B0 + 0.05**(문맥이 값을 해야 한다)

**shadow 승격(v2 §3 ②′)**: ④ 4/4 · 샤프 ≥ 대조 + 0.05 · ⑥ 충족이면 후보 — 채택 문턱 미달이어도 전방 자료로 다시 잰다.
**기록**: 지수 대비 IR·하락 포착률, 팔별 선택 횟수, 연 노출 전환·회전, 국면별 표, 시드 흩어짐(B1 샤프 표준편차).

## 먼저 하는 배관 점검(카나리) — 판정이 아니다

`v2_bandit.py canary` 는 문맥에 **정답 칸**(다음 세션 벤치 수익 부호)을 하나 더 넣고 굴린다. 2026-08-20 카나리의 교훈:
"못 배운다" 를 말하기 전에 배관이 살아 있는지, 필요한 표본이 있는지 본다. 판정 기준은 이렇게 읽는다.

- 정답을 주고도 대조를 못 이긴다 → **배관·표본 문제**다. 본 판정을 돌리지 않고 원인을 고친다(팔 선택 분포·보상 크기·지연).
- 정답을 주면 이긴다 → 배관은 산다. 그 다음 본 판정이 뜻을 갖는다.

카나리 결과는 `docs/trials-postmortem.md` 에 적고 **채택 근거로는 쓰지 않는다**.

## 한계 — 미리 적는다

- **밴딧은 부분 관측이다.** 그날 고른 k 의 보상만 본다(반사실 보상을 주지 않는다 — 주면 실전에 없는 게임이 된다).
  그래서 821세션 × 4팔 = 팔마다 ~200 표본이고, 일 초과수익의 잡음(σ ≈ 1%)에서 잴 수 있는 차이는 대략 연 3%p 이상이다.
  **이보다 작은 진짜 차이는 이 표본으로 못 가른다** — 판정에 "표본 부족" 을 쓸 수 있다는 뜻이고, 그건 기각이지 무승부가 아니다.
- HMM 은 지수 세 피처만 본다(시장 폭·신용 스프레드 없음). 월 재적합이라 상태 의미가 조금씩 움직인다(상태는 평균 수익 순위로 고정).
- 박스장에서는 노출 조절 자체가 비쌌다(BB: C1·C2 모두 C0 보다 5~6%p 낮다). 밴딧이 그 사실을 배우면 k=1 에 붙을 수 있고,
  그건 실패가 아니라 "노출 조절은 지금 자료에서 값이 없다" 는 답이다 — 그렇게 읽는다.

## RL 실패 복기에서 가져온 방지책

| 지난 실패 | 이번 장치 |
|---|---|
| 보상 평평 · "덜 행동하기" 를 먼저 배움(1회차) | 행동이 노출 하나뿐이라 비용 회피로 도망갈 자유도가 없다. 팔별 선택 횟수·팔별 평균 보상을 같이 본다 |
| 관측 원값이 그래디언트를 삼킴(2회차 r5) | 문맥 8칸 전부 고정 스케일 O(1), 원값 금지를 테스트가 강제 |
| 현금 타이밍을 외움(2회차 r6) | 현금 비중은 행동이 아니다(k 가 정한 몫만 현금). 에폭 없는 단일 통과 + 지연 2 |
| 종목 하나를 외움(9/2 베타) | 종목 비중을 아예 안 건드린다(L0·L1) |
| 목적 ≠ 판정 지표(시행 L 의 교훈) | 보상 = 지수 초과 − 낙폭 벌점, 판정 = 지수 대비 샤프·MDD·IR — 같은 방향 |
| 카나리 예산 오판(8/20) | 카나리를 먼저 돌리고, 표본으로 가를 수 있는 최소 차이를 위 "한계" 에 미리 적었다 |
| 대조가 약함 | 대조 셋(C0·C1·C2) + 밴딧 자기 대조(B0) |
| 안전장치가 RL 을 덮어씀(선행 프로젝트) | 행동은 세션 전 창고에, 집행은 읽기만(불변식 6). 반영률은 shadow 에서 실측 |
| 평가 도구가 없었다 | 도구 하나에 `smoke`·`canary`·`judge`·`train`·`act` 가 같이 있다 |

## 실행

```
.venv/bin/python tools/v2_bandit.py smoke                      # 합성 자료(아무 때나)
.venv/bin/python tools/v2_bandit.py canary --i-registered      # 배관 점검
.venv/bin/python tools/v2_bandit.py judge  --i-registered --save
```

판정 뒤: 채택이면 `train` → `act`(22:50 크론, hmm-v1 과 나란히) → shadow 장부. **채택·승격 전에는 크론을 걸지 않는다.**

## 사용자 승인에 올릴 결정 사항

1. **R0 을 10/5 에 돌릴까** — v2 로드맵에 있는 일이지만, "10/19 전엔 새 시행 등록 안 함"(9/23 지시)과 겹친다.
2. **행동 집합** {0.50, 0.70, 0.85, 1.00} 네 개로 갈까, BB 와 완전히 같은 {0.5, 0.8, 1.0} 세 개로 갈까(표본은 팔 수에 반비례한다).
3. **채택 대조를 `max(C1, C2)` 로** 두는 것(현행 규칙과 HMM 둘 다 넘기). 더 느슨하게 C1 만 두면 채택이 쉬워진다 — 초안은 엄한 쪽이다.
4. 채택·승격 시 **shadow 장부를 새로 만들까**(`data/_k200bandit_shadow`), 아니면 hmm-v1 장부를 갈아탈까.
