# 사전등록 — 벤치마크 정렬 구성 (2026-09-02, 방향 ① 2차 · 퀀트 표준 기법 참조)

베타 정렬 선정(beta-aligned-selection-2026-09.md)이 밝힌 것: **유니버스 β 가 0.4** 라 종목을 어떻게 골라도
동일가중 24 로는 시총가중 KOSPI200(초대형주 집중 랠리)을 못 쫓는다. 퀀트 업계가 시총가중 벤치마크를 이기는
표준은 선정이 아니라 **구성**이다 — 인핸스드 인덱싱(Grinold–Kahn: 지수 가중 위에 알파로 ± 액티브 가중, 추적오차
예산 안에서) 과 코어-새틀라이트. 이 시행은 그 셋을 우리 알파(fundamental) 위에서 잰다. 시행 1회 (family `portfolio`).

## 데이터
- beta-aligned 와 같은 발판 + **시가총액** `market_stats(metric=market_cap)` (KRX, 세션별 · t 값을 t 결정에 쓴다).
- 지수 대용: 시총 상위 200 종목의 시총가중 포트(K200 대용, 리밸런스 매일) — KOSPI200 구성종목 명단이 없어
  근사한다. 대용의 지수 대비 추적오차를 함께 적는다(대용이 지수를 못 따라가면 결과 해석에 한계).

## 판정 (고정) — 기준선은 KOSPI200 이고, 이 창의 성격상 지표는 **추적오차와 IR** 이 주인공이다
① IR(vs K200) > 0 이고 BASE 보다 ≥ 1.0 높음 ② 연 초과수익(vs K200) > BASE + 20%p ③ MDD 가 K200 MDD 보다 얕거나
2%p 이내 ④ 지수 하락일 초과수익 ≥ 0 (지수보다 덜 잃는다). 넷 다 → 채택 후보(§3 risk_parity 와의 결합·배선은 별도).
읽을 때 주의: 시총가중 코어는 정의상 지수를 따라가므로 ①②는 **알파 부분이 지수를 상대로 양(+)인가**의 시험이다.
