# 사전등록 — M4 5회차: 매매 전반 DRL, 마지막 시도 (2026-09-04 · 남은 시도 2회 중 1회 소진)

사용자 결정: "진짜 마지막으로 DRL 에서 매매 전반을 가르쳐 보자. 할 수 있는 모든 수단을 동원해라. 안 되면 네가 말한 대로
진행한다." 그래서 이 판은 **네 번의 실패 원인을 전부 장치로 막은 설계**다. 통과선은 측정 전에 여기서 고정한다.

## 지난 실패와 이번 장치 — 하나씩 대응

| 매매 전반 베타(9/2): 종목 하나로 +680% | softmax 가 유니버스 전체에 걸려 승자 하나를 외움 | **비중 상한 6.25%(유효종목 ≥16) 강제 투영** + 유효종목 벌점 + 잔차 파라미터화(랭커에서 출발) |

| 대조가 약했다 | fundamental 대비 | 대조 = **오늘 채택된 EMA5·3N ranker 동일가중 24**(제일 센 현행) |

## 데이터 (고정)
- 국장 2024-02-01 ~ 2026-06-30 (ranker 워크포워드 이력, 홀드아웃 봉인). 종목 피처(세션 안 rank-gauss): chart·event·flow·
  fundamental·regime·risk·ranker + ranker 5세션 EMA(직전까지) = 8, 상태: 보유비중·보유일/60 = 2 → 10. 명단 `universe`, 위험 하한 컷 없음
  (정책이 risk 를 본다). 수익 t+1→t+2 수정종가, |일수익|>50% 결측. 대조 벤치 = 명단 동일가중.
- IC 판정 타깃 h5 = `ic.build_targets` (랭커 시행과 같은 규약).

## 정책·행동·보상 (고정)
- 점수 s_i = z_ranker_i + f_θ(x_i, 횡단면 평균 풀링) — f 의 마지막 층 0 초기화(출발점 = ranker). 공유 MLP 10→32→32.
- 비중 w = softmax(s) 를 **상한 1/16 로 5회 반복 투영**(초과분 비례 재분배). 롱온리 합 1, 현금 없음.
- 보상: 에피소드(무작위 120세션, 첫날 보유 = ranker 상위24 동일가중) 안에서 일별 x_t = w_t·r_{t+1} − 0.0041·‖w_t − w̃_{t−1}‖₁ − r̄_{t+1}.
  **손실 = −mean(x)/std(x)** (IR) + 0.01·relu(16 − 1/Σw²) 평균. 학습 시 피처에 N(0, 0.1) 잡음·드롭아웃 10%.
- Adam lr 5e-4 · weight decay 1e-3 · 스텝 400(스텝마다 새 에피소드) · 클립 1.0 · 시드 0·1·2 → 점수 평균 앙상블.
- 조기종료: 학습창 마지막 60세션(퍼지 5)을 검증으로 떼어 20스텝마다 검증 IR 을 재고 **최고 검증 스텝**의 가중치를 쓴다.

## 워크포워드 (시행 L 과 동일)
확장창, 판정 5블록 × 20세션(2026-01-08~2026-06-08), 퍼지 5. 판정 세션 100.

## 채택 기준 — 다섯 모두 (측정 전 고정)
① 정책 비중 그대로의 **순일수익 − 대조(EMA5·3N EW24 순일수익)** 의 NW t(lag 4) ≥ 2.0
② 정책 MDD 가 대조보다 3%p 넘게 나쁘지 않음
③ 구조: 판정 100세션 평균 유효종목 ≥ 12, 최대 단일 비중 ≤ 10% (외운 판이면 여기서 걸린다)
④ 정책 점수 IC(h5) ≥ ranker IC − 0.01 (순위를 망치지 않았는가)
⑤ 최악 20세션 블록의 (정책 − 대조) 누적 ≥ −3%p
함께 적되 기준 아님: 학습창 IR, 검증 IR, 회전, 시드별 결과.
