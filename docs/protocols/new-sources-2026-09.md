## 공통
- 시장 KR. 판정은 **2026-06-30 이전**(홀드아웃 2026-07-01~ 은 열지 않는다). 벤치마크 KOSPI(`benchmark.kr_index`).
- 이벤트 연구: 비정상수익 AR = 종목 수익 − 지수 수익. 창 [t+2, t+21] 누적 CAR. NW t(lag 20).
- 횡단면 신호: 세션별 순위 정규화(base.rank_score) → IC(h5·h20) NW t → **fundamental 위 한계기여 ΔIC(h5)**
  (`ic.marginal_shares`, t ≥ 2.0). 개별 IC 만 좋고 한계기여 0 이면 기각(event 의 선례).
- 시행 수: 4건 = research_trials family `sources` 4회. 도구 `tools/trial_new_sources.py --trial C|D|E|F --save`.
- 채택 시 코드 반영은 **관찰 모드(가중치 0)** 로 시작(CLAUDE.md 개발 원칙).

## 시행 C — PEAD (실적 발표 후 드리프트)
- 사건: `documents` doc_type=earnings · 제목에 "잠정" · "기재정정" 제외 (2025-04~2026-06, ~2,900건).
- 공시 시각을 모르므로 **발표 반응 = [t, t+1] 2일 AR**(t = 공시일 세션). 부호는 이것이 정한다.
- 이벤트 판정: 발표 반응 상위/하위 3분위의 CAR[t+2, t+21] 차이 > 0, NW t ≥ 2.0.
- 신호: `pead_60` = 최근 60세션 안 마지막 발표의 2일 AR(없으면 결측). 부호 **+**. 채택 기준: 공통(한계기여 t ≥ 2).
- 채택 시: 새 Analyst `earnings_drift`(event 와 별개 — event 는 기업행위, 이것은 실적 반응).

## 시행 D — 내부자 순매수
- 데이터: DART `elestock`(임원ㆍ주요주주 특정증권등 소유상황보고) → 새 표 `insider_trades`
  (보고일·보고자·직위·주요주주 여부·보유수·**증감수**). 수집기 `tools/backfill_insider_dart.py`.
  observed_at = 보고일 18:00 KST(공시 시각 미상 → 보수적으로 장 마감 뒤).
- 신호: `insider_net_60` = Σ(증감주수 × 그날 종가) / 20일 평균 거래대금, 최근 60세션. 부호 **+**.
  임원·주요주주 모두 포함, 증감 0 행 제외. 주식매수선택권 행사 등 구분은 API 에 없어 포함한다(한계로 적는다).
- 이벤트 판정: 순매수(증감 > 0) 보고일 뒤 CAR[t+2, t+21] > 0, NW t ≥ 2.0. 순매도는 대조.
- 채택 기준: 공통. 채택 시 새 Analyst `insider`.

## 시행 E — 월 리밸런스 (회전 비용)
- 현행: 매일 상위 24 진입 · 48위 밖 퇴출(완충). 변형: **20세션마다** 상위 24 재선정, 사이는 보유 유지.
  점수 `data/_diag/scores-fundamental-KR.pkl`, 수익 h1 타깃, 비용 편도 0.41%.
- 지표: 순IR(연율)·연회전. 채택 기준: 변형 순IR ≥ 현행 순IR 이고 회전 절반 이하. 미달이면 기각(현행 유지).
- 채택 시: `selector.rebalance_interval_sessions` 설정 신설 + 세션 배선(사전등록 뒤 별도 커밋).
