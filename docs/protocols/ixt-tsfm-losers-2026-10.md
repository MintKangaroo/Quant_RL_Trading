# 사전등록 초안 — IX-T: 지수에서 TTM 제로샷 예측의 패자만 빼고 든다 (family `selection` · 예산 1 · 처리 1 · 대조 IX0)

## 왜

TSFM 제로샷(학습 없음, 종가 256일만 입력)의 국장 5일 수익 IC 가 모델 공개일+3개월 뒤 창에서 +0.06~+0.13(t 3~7.5)이었다. 매일 예측(318세션)으로 보면
실력은 패자 쪽이다(최하 10분위 5일 −1.2~−1.4%). 랭커의 대형 패자 판별이 공매도 재개(2025-03-31) 뒤 사라진 것과 달리 TTM 의 패자 판별은 재개 뒤 창에서 나왔다.
탐색: 유동주 상위 300 시총가중(상한 30%) − TTM 하위 10%, 5세션 재조정, 비용 후, **하루 늦춤** +1.30%p/년(IR 1.54, 이긴 5일 창 59%) · 동일가중 하위 20% +9.37%p(IR 1.97).
Chronos-Bolt 는 하루 늦추면 시총가중에서 −0.61%p 라 TTM 을 쓴다.

## 정의 — 실전 배관, 설정 덮어쓰기로만(불변식 5)

| 장부 | 설정 | 무엇 |
|---|---|---|
| **IX-T**(처리) `data/_ixt_shadow` | `config/shadow/ixt.config-overrides.yaml` | 거래가능 KOSPI200 구성종목 · **tsfm 신호 하위 10% 제외**(`selector.floor_analyst: tsfm` · `selector.risk_floor_percentile: 0.10`) · 유동시총 가중 · 상한 30% |
| **IX0**(대조) `data/_ix0_shadow` | IX 등록(`ix-index-minus-losers-2026-10.md`)의 대조 그대로 | 같은 배관, 제외 없음 |
| 기록 | `data/_ix_shadow` · `data/_idxv6_shadow` | IX(랭커 패자) · 지수+V6 |

- IX-T 설정은 IX0 와 **두 줄만** 다르다(하한 10% · 기준 tsfm). V6 노출 · 재조정 10세션 · 4조각 집행 · 비용 · 최소 주문금액 10만원은 모의계좌 규칙 그대로.
- **tsfm 신호**(`tools/tsfm_signal.py`, 버전 `ttm-r2-zeroshot-L256-v1`): 밤마다 마지막 국장 종가까지의 보정 종가 256일 → TTM r2(`ibm-granite/granite-timeseries-ttm-r2`, 제로샷) 지평 6 예측 → r̂ = p̂(t+6)/p̂(t+1) − 1 →
  그날 계산 대상(원 거래대금 20일 상위 300 ∪ K200 구성) 안 백분위를 [−1, 1] 점수로. `valid_from = observed_at = 계산 시각` → **다음 세션 결정에만 보인다**(하루 늦춤). 제약 전용(알파 합성 밖, 신뢰도 0).
- tsfm 점수가 없는 구성종목은 자르지 않는다(위험 하한 규칙 그대로) — 흔적에 남는다.
- 크론: 신호 `15 0 * * 2-6`(`scripts/run_tsfm_signal.sh`) · 장부 `35 0 * * 2-6`(`scripts/run_shadow_ixt.sh`, 10/13 전 날짜 가드). 첫 세션 2026-10-12. 자본 5.03억.

## 판정 — 전방 250세션(약 1년), 한 번 (IX 와 같은 꼴)

**미리 적는 검정력**: 탐색 효과 +1.3%p/년 · IR 1.5 가 그대로면 NW t 2 에 약 2년이 든다. 1년 전방은 "방향·실행 가능성" 확인이다. 기준을 결과에 맞춰 바꾸지 않는다.

1. **방향**: IX-T − IX0 연환산 ≥ 0, **그리고** 이긴 10세션 구간 비율 ≥ 50%.
2. **실행 비용**: IX-T 연회전 ≤ IX0 × 3 (하한 교체가 회전을 키운다 — 탐색 회전 7~9%/5일).
3. **위험**: IX-T MDD 가 IX0 보다 1%p 넘게 깊지 않다.
4. **운영**: tsfm 신호가 판정 세션의 95% 이상에서 제때(결정 전) 적재됐다 — 빠진 날은 하한 없이 돌았으므로 그 비율을 적는다.

- 60세션 시점에 **기록만**(판정 아님). 넷 다 통과 → "지수 코어 하한을 tsfm 으로" 를 **후보**로 올린다(실전 전환은 사용자 결정, 실자금 관문과 별개).

## 한계

1. 탐색 창 1.3년 · 대부분 급등장 · 조합 선택(모델·비율·가중) — 낙관적이다.
2. TTM 은 범용 시계열 모델이다. 왜 국장에서만 맞는지(미장 IC ≤ 0) 기제를 모른다 — 한국 단기 되돌림·개인 주도 가격 오류와 맞물린 것으로 추정할 뿐이다.
3. 신호 계산이 실패하면 그날 하한이 빠진다(IX0 와 같아진다) — 운영 기준 ④로 센다.
4. IX(랭커 패자)와 동시에 돈다. 둘의 결합은 새 등록 없이 하지 않는다.
