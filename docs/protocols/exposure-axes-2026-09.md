# 시행 V — 노출 축 셋 중 무엇이 값을 하나 (사전등록 2026-09-18)

## 왜 재나

시행 U(`exposure-timing-2026-09.md`)는 노출 축을 **통째로** 끄면 판정 360세션에서 연 +7.7%p 가
남고 MDD 는 같다는 것을 보였다(+16.9% 대 +9.2%, 둘 다 −17.7%). 그 비교는 데드밴드 경계의
부동소수 결함에 **영향받지 않았다** — U0 와 U1 은 경계 수정 전후로 숫자가 한 자리도 안 바뀌었다.

그런데 "전부 끈다/전부 둔다" 는 거칠다. 노출은 축이 셋이고 서로 다르게 작동한다. 판정 창에서
**추세 77 · 국면 53 · 압축 35** 세션씩 걸렸다. 어느 축이 비용을 내고 있는지는 아직 모른다.
하나만 문제일 수도 있고, 하나는 값을 할 수도 있다.

## 무엇을 재나

시행 U 와 **완전히 같은 대리 경로·판정 창·비용 규칙**을 쓴다. 다른 것은 배수를 만드는 방식뿐이다.

- **대리 경로**: `trial_alpha_breadth.path(panel, idx, 24, 0.0625)` 의 비용 후 일수익.
- **판정 창**: 2025-01-02 ~ 2026-06-30. **홀드아웃(2026-07-01~)은 열지 않는다.**
- **모의계좌 실적은 판정에 안 쓴다.** 동기일 뿐이다.
- 지수 `KR:IDX:KRX 300`, 배수·임계는 창고 `exposure` 설정 그대로, 세션 t 의 배수는 t−1 종가까지로.
- 데드밴드는 **끈다**(시행 U 에서 무용으로 판정됐다). 이 시행은 축을 묻는다.
- 축 조합의 배수는 현행과 같은 규칙으로 **고른 축들의 최솟값**이다.

## 변형 (측정 전 고정, 여덟)

| 이름 | 켠 축 |
|---|---|
| **V0** | 추세 · 국면 · 압축 (현행) |
| **V1** | 없음 (노출 축 끔) |
| **V2** | 국면 · 압축 (추세 뺌) |
| **V3** | 추세 · 압축 (국면 뺌) |
| **V4** | 추세 · 국면 (압축 뺌) |
| **V5** | 추세만 |
| **V6** | 국면만 |
| **V7** | 압축만 |

"하나 뺀 것"(V2~V4)은 **한계기여**를, "하나만"(V5~V7)은 **단독 값**을 말한다. 둘을 같이 봐야
"셋이 겹쳐서 쓸모없는 것" 과 "그 축 자체가 해로운 것" 이 갈린다.

## 채택 기준 — V0 대비 **넷 다** 통과해야 채택 (측정 전 고정)

| | 기준 | 값 |
|---|---|---|
| ① | 비용 후 연수익 | ≥ V0 |
| ② | MDD | ≥ V0 (더 얕거나 같다) |
| ③ | 배수 전환 횟수 | ≤ V0 |
| ④ | **최악 20세션 누적수익** | ≥ V0 |

④ 를 넣는 이유: 이 장치의 존재 이유가 **나쁜 구간을 덜 나쁘게** 만드는 것이다. 전체 MDD 만
보면 "평소엔 멀쩡한데 최악에서 더 깎이는" 조합을 못 거른다. 축을 빼는 판단이라 방어 쪽 기준을
하나 더 둔다.

- 여럿이 통과하면 **켠 축이 적은 것**을 고른다(단순한 쪽). 같으면 전환이 적은 쪽.
- 하나도 통과 못 하면 **현행 유지**(V0).
- **V1 도 후보다.** 시행 U 에서는 일부러 뺐지만, 이 시행은 "축이 값을 하나" 를 정면으로 묻는
  자리이고 사용자가 그 질문을 명시적으로 열었다(2026-09-18). 대신 ④ 가 방어 쪽 바닥을 지킨다.
- 표본 미달(판정 세션 < 300)은 기각이 아니라 **보류**.

## 안 보는 것

홀드아웃, 모의계좌 실적, 미장. **결과를 보고 변형을 추가하지 않는다** — V0~V7 이 전부이고,
여기서 진 조합은 이 분기에 다시 열지 않는다. 기준도 결과를 보고 바꾸지 않는다.

함께 적되 기준 아님: 축별 발동 세션 수, 평균 배수, 전반/후반 연수익.
