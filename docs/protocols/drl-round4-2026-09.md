# 사전등록 — M4 4회차: ranker 위의 배분 DRL (2026-09-03 등록 · 남은 시도 2회 중 1회)

## 왜 다시 여나
3회차 파일럿(2026-09-01)은 반영률 0.95 로 운전대를 잡고도 균등가중을 못 이겼다 — "상위 24 안에 배분으로
얻을 알파가 없다". 그 뒤 **처음으로 fundamental 을 이긴 학습 신호**가 생겼다(시행 L, `ranker`, 국장 ΔIC
+0.028 NW t 2.88 · 미장 +0.031 t 4.40). 사용자 지시("정보가 충분해지면 DRL 제안")의 트리거 ①이다.
사용자 결정: "진행하자" (2026-09-03 12:5x).

## 3회차와 다른 것 셋 — 이것만 다르다
1. **재료.** 후보 24 와 상태값 0번 칸(종합점수)이 fundamental 단독이 아니라 **ranker 가 실제 가중을 받은
   합성**이다. `analyst_weights` 의 한계기여(LOO ΔIC) 규칙이 정하고, 손으로 안 정한다. ranker 점수×신뢰도
   슬롯도 관측에 들어간다(슬롯 9개 중 마지막, `allocator/cache.ANALYST_SLOTS`).
   ranker 이력은 워크포워드 모델 열로 백필한다(`tools/backfill_ranker_signals.py`, 세션 S 는
   usable_from ≤ S 인 모델만). 그래서 학습 창은 **2024-02-01 부터** (모델 열이 2024-01-31 부터).
2. **보상 기준선 = 후보 균등가중.** `--reward-baseline candidates` → r = (r_port − invested·r̄후보) − w(d)·Δd − cost.
   판정 지표(균등가중 대비 우위)와 학습 목적이 같아진다. 시행 L 이 이긴 이유(목적 = 판정)를 그대로 옮긴 것.
   리턴 정규화(running std)는 그대로라 사실상 스텝 단위 IR 이다.
3. **학습 창.** 2024-02-01~2025-12-31(≈470세션), 검증 2026-01-02~06-30, 홀드아웃 2026-07-01~ 은 봉인.
   시작점 반복 ≤150 → 본 학습 8M 스텝. 나머지(현금 고정·보유 출발·코사인 감쇠·C2 비용 포함·검증 폴드로
   체크포인트 선택·지연 고정)는 3회차 설계 그대로.

## 순서 (체인 `scripts/chain_drl_r4.sh`, 단계마다 로그 표식 — 끝난 단계는 재기동 시 건너뜀)
0. 전 Analyst 한계기여 재측정(`measure_ic --save`, KR·US) 완료 대기 — ranker 가 실가중을 받는 자리
1. ranker 모델 열 확장: 월말 2024-01-31 ~ 2025-05-31 (국장 신호만으로 학습)
2. ranker 신호 백필: KR 2024-02-01 ~ 2026-09-02, US 2025-08-05 ~ 2026-09-02
3. ranker 워크포워드 IC 이력: `backfill_ic_history --analyst ranker --market KR --start 2024-08 --end 2026-08 --save`
   (200일 하한이라 ~2024-12 부터 통과 → 그 뒤 시점의 후보에 ranker 가 들어간다)
4. RL 세션 캐시 재굽기: KR 2024-02-01 ~ 2026-08-31 `--rebuild`
5. 파일럿 게이트(150업데이트, 3회차 기준 그대로): 마지막 3개 체크포인트 검증 우위 > 0 이고 격차가 벌어지기만
   하지 않을 것. 불합격이면 본 학습을 띄우지 않고 **시도를 소진하지 않는다**
6. 본 학습 → 검증 폴드 체크포인트 선택 → 홀드아웃 판정(`evaluate_policy --save`, 금고 개봉 1회) →
   `promotion_gate` → 통과 시 모의계좌

## 판정 (미리 고정)
- 파일럿: 위 5.
- 본판: 홀드아웃에서 **균등가중 대비 우위 > 0** 이고 학습 구간 우위 > 0 (`evaluate_policy` 규칙 그대로) +
  `promotion_gate`. ΔIR 의 NW t 는 함께 적되 36일 홀드아웃에서는 기준으로 쓰지 않는다(판정력 없음).
- 실패 시: 4회차는 소진. 남은 1회는 **집행 RL 2차**(룰 TWAP 통과 뒤)에 남긴다. 배분 RL 변형은 더 안 연다.

## 이 등록이 못 고치는 것
ranker 가 fundamental 보다 낫다는 것과 "그 24 안에서 배분으로 얻을 것이 있다" 는 것은 다른 명제다. 파일럿의
검증 우위가 0 근처면 3회차와 같은 답 — 그때는 배분이 아니라 **선정(상위 N·완충)** 쪽 등록으로 간다.
