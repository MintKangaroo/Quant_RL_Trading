# 사전등록 — 시행 T2P: 잔차 정답(T2) GBM × P1-b′ 구성 (2026-10-14 초안 · family `selection` · 예산 1 · 국장)

## 1. 왜

정답을 "세션 안 h5 수익 순위"(T0, 현행)에서 "업종·β·시총에 회귀한 잔차 수익 순위"(T2)로 바꾸면, 같은 6점수·같은 GBM·현행 구성에서
**회전이 21.8 → 9.7/년으로 반 넘게 줄고**(점수가 스타일 쪽으로 출렁이지 않는다) 비용 9.0 → 4.0%/년 · MDD −26 → −17% · 비용 후 − U +0.9 → +5.6% 였다.
IC 이득은 작았다(+0.0043, t 1.6). 즉 T2 의 값은 **정보가 아니라 회전**에서 온다 — P1-b′(회전 줄이기, 11/23 금고)와 겹치는 효과다.
질문: **P1-b′ 구성 위에서도 T2 정답이 회전을 더 줄이고, 비용 후로 P1-b′(C0 점수)보다 낫거나 적어도 나쁘지 않은가.**

## 2. 처리 · 대조 (측정 전 고정, 변형 하나)

| 이름 | 점수 | 구성 | 역할 |
|---|---|---|---|
| **V1** | T2 GBM(국장 단독, 6점수, 정답 T2) | P1-b′ B1′(N100 · 5N · R20 · θ1.0) | 처리 |
| K1 | C0(현행 랭커 이음) | P1-b′ B1′ | **대조 — P1-b′**(같은 구성, 현행 정답) |
| K0 | C0 | 현행(N24 · 3N · R10) | **대조 — 현행** |
| 기록 | T0 GBM(국장 단독, 정답 T0) | P1-b′ B1′ | 같은 규격·정답만 다름(기준 아님) |

- T2 정답 정의는 번역 손실표 §1-C 그대로(`diag_translation_loss.targets`): 세션마다 r5(±50~100% 자름)를 [업종 더미(DART 중분류, 2026-08 적재본 고정 속성), β(K200 120일, [−1, 3]), log 시총]에
  최소제곱한 잔차의 rank-gauss. 피처 = C0 6점수, 하이퍼파라미터 = 시행 L, 블록 = C0 규격(20세션 · 첫 블록 155 · 퍼지 5 + 엠바고 5).
- 변형은 B1′ 하나다(사용자 "최소로"). B2′(N24·R20) 결합은 재지 않는다.
- 포트·위상 평균·비용·EMA5 는 BLT 등록(`be2-low-turnover-2026-10.md` §2)과 같은 코드(`trial_sprint_1123.arm_book`).

## 3. 주 시험 — 긴 과거 사다리

- 점수: `data/_diag/eval-ladder/scores/T2·T0·C0`(10/14 와 같은 파일, 새 학습 없음). 창 **2022-06-28 ~ 2026-09-30**(T2 첫 블록부터, 약 1,040세션). 봉인 `DATE_CAP` 9/30.

| 칸 | 기준 | 값 | 성격 |
|---|---|---|---|
| ①a·①b | T2 IC · D10−D1 | > 0 · t ≥ 3, 특수 뺀 쪽 > 0 · t ≥ 2 | 원리 |
| ②a | **비열등** — ΔIC(T2 − T0) + 0.002 의 NW t ≥ **2** 그리고 특수 뺀 쪽 ΔIC ≥ −0.002 | — | 정답을 바꿔 순위 정보가 크게 줄지 않았다(주장 아님) |
| ③a | 비용 후 짝 차(V1 − K0) | 전체 > 0 · 특수 뺀 쪽 > 0 · 시드 4/5 | 번역(부호) |
| ③b | 비용 후 짝 차(V1 − K1 = 대 P1-b′) | 전체 > 0 · 특수 뺀 쪽 > 0 | "P1-b′ 에 더해 값이 있다" |
| ③c | 비용 후 − 유니버스 EW | 두 쪽 > 0 | 선택 알파 |
| ③d | 비용 후 − K200 | 특수 뺀 쪽 > 0(전체 기록) | 지수 대비 |
| ③e | MDD | ≥ K0 − 2%p · ≥ K200 − 5%p | 해 방지 |
| ③f | 연 회전 | ≤ K0 × 0.75 | (B1′ 이라 거의 자동 — 기록에 가깝다) |
| **③g** | **재조정일 회전 짝 차(V1 − K1)의 NW t** | **≤ −3** | **주장 — T2 정답이 P1-b′ 위에서 회전을 더 줄인다** |

- **주장하는 칸은 ③g 하나**(t ≥ 3 상당). 회전은 수익보다 잡음이 훨씬 작아 긴 과거에서 검정력이 있는 유일한 포트 지표다. 재조정일 = 둘 중 하나라도 회전이 난 날.
- 세 줄(전체 / 특수 뺀 쪽 / 특수만) 출력 · 판정 문구 · nan 멈춤 · 다중검정 19 는 BLT 와 같다(`trial_sprint_1123.gates`).
- 금고 확인 여유(`margins`)는 V1 − K0 일수익 짝 차와 ΔIC(T2 − T0)의 30세션 블록에서(BLT §3-3 과 같은 규칙).

## 4. 검정력

- ②a(비열등): 10/14 ΔIC +0.0043 · t 1.64 · 1,035세션 → 표준오차 ≈ 0.0026. 참 효과 0 이면 비열등 t = 0.002/0.0026 ≈ 0.77 → 통과 확률 ≈ 13%,
  참 효과가 관측의 절반(+0.002)이면 t ≈ 1.5 → ≈ 31%, 관측 그대로면 2.4 → ≈ 66%. **같은 자료라 관측 그대로 나온다** — 사실상 통과가 예상된다(§7).
- ③g: 처리·대조 둘 다 B1′(θ1 비용 인지)라 회전 수준이 이미 낮다(C0 × B1′ 4.8/년). T2 가 현행 구성에서 회전을 0.45 배로 줄였으니 B1′ 에서도 같은 비율이면 4.8 → 약 2.2/년.
  재조정일 약 52일 짝 차의 일관성에 달렸고 **정확한 검정력은 등록 전에 못 쟀다**(B1′ × T2 장부를 돌리는 것이 주 시험 계산 자체다). 위험: θ1 이 이미 작은 교체를 막아 T2 의 몫이 작을 수 있다.
- ③b(대 P1-b′ 부호): 기대 이득 ≈ 회전 감소 × 0.41% ≈ 연 1%p 안팎 + MDD 개선분. 비용 후 연 짝 차의 표준오차 ≈ 3%p 라 **전체·특수 뺀 쪽 둘 다 양일 확률은 40~60%** —
  이 시행에서 가장 떨어지기 쉬운 칸이다.
- 금고 Q1(ΔIC T2 − T0, 30세션): `power --trial T2P` 로 블록 표준편차를 재 이 절 끝에 붙인다(이미 본 T2·T0 점수만, 가벼움).


**실측(`power --trial T2P`, 2026-10-14 10:59, 이미 본 T2·T0 점수만)**: 짝 계열 1,035세션 · 일 표준편차 0.0495 · 긴 과거 평균의 NW 표준오차 0.00265 →
t ≥ 3 최소 탐지 효과(80%) +0.0102(ΔIC 를 주장 칸으로 둘 수 없다는 확인). 30세션 블록 평균 표준편차 **0.0150** → 금고 Q1 여유 **−0.0247**,
δ 0.001~0.003 에서 30세션 평균 > 0 확률 53~58% · Q1 통과 확률 96~97%(해 방지 칸이라 높다).

## 6. 전방 감시

- shadow 는 이 등록에 **만들지 않는다**(T2 실전 모델·Analyst 배선이 없다 — 얼린 T2 를 매일 채점하는 `t2fa` 류 Analyst 가 필요하다. 금고 확인 통과 뒤 사용자 결정).
- 실전 반영 결정 때: 대조 장부 = P1-b′ shadow(`_p1b_shadow`). 순차 검정(α 0.10, t* 250) 짝 = T2 장부 − P1-b′ 장부 일 초과수익 + 연 회전 비.
  뺄 조건: 상한 < 0 · MDD 가 P1-b′ 보다 3%p 넘게 깊다 · 60세션 회전 비가 1 을 넘는다(회전 주장이 깨짐) — 사용자에게 올린다.

## 9. 사용자에게 확인받을 것 (고정 전)
