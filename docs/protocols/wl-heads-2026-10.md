# 사전등록 — WL: 오를 종목·망할 종목을 따로 맞히는 두 갈래 GBM (family `ranker` · 예산 1 · 처리 2)

## 왜

랭커의 실력이 패자 쪽에 몰려 있다(10분위 진단). 회귀 목표(rank-gauss y5)는 분포 전체를 맞히려 해서 상위 꼬리를 따로 배우지 않는다.
**목표를 꼬리로 바꾸면** — (W) 오를 종목 상위 10% 를 직접 맞히면 상위 24 가 나아지나, (L) 망할 종목 하위 10% 를 직접 맞히면 패자 빼기가 나아지나.
문헌(Stambaugh·Yu·Yuan 2012)은 W 가 어렵다고 예측한다 — W 가 실패하면 "공개 재료로 롱 알파는 없다" 의 직접 증거가 된다.

## 정의

- 패널: `data/_diag/fa2021/panel/panel-KR-KR+US-20211110-20260630.parquet` 의 **국장 행만**(3,144,253행 · 1,134세션 · 세션당 2,598~). 피처 = 회차 C1 의 76개(`final_round_kit.feature_names(blocks_of(("KR","US"), FA2021 raw))`).
- 블록·학습 끝점·판정 행 = `final_round_kit.blocks`·`train_end`·`block_rows`. GBM = `trial_ranker_kit.fit`(시행 L 하이퍼파라미터), 시드 0~4.
- 세 갈래 — 목표만 다르다: **C1**(대조) y5 회귀 · **W** y5 가 그날 횡단면 상위 10%(이진, binary logloss) · **L** 하위 10%(이진).
- 등록 전 점검(10/9, 수익 없음): W 라벨 비율 10.02% · L 9.98% · y5 결측 0 · 피처 76.

## 판정 (국장 · W-fa2021 판정 세션 · 비용 후)

**W(오를 종목)** — EMA5 → 상위 24 · 완충 3N · 재조정 10세션 · 동일가중(`trial_ranker_kit.portfolio`), 대 C1 점수의 같은 포트:
1. 시드 평균 연 ≥ C1 + 1%p, 그리고 일별 차이 NW t(lag 4) ≥ 2.0 · 2. 시드 4/5 · 3. 국면 넷(하락·반등·박스·급등) 모두 ≥ C1 − 1%p · 4. MDD 2%p 넘게 깊지 않고 회전 ≤ C1 × 1.2.

**L(망할 종목)** — 거래가능 유니버스 동일가중에서 그날 점수 하위 10%(L 은 확률 상위 10%)를 뺀 포트, 재조정 10세션, 대 C1 점수로 뺀 같은 포트:
1. 연 ≥ +0.5%p, NW t ≥ 2.0 · 2. 시드 4/5 · 3. 국면 넷 모두 ≥ −0.5%p.

둘은 따로 판정한다. 통과 = 후보. 기록: 유니버스 동일가중 연수익.
