## v2 — 바꾸는 것은 머리 채택 규칙 하나

모델(얼린 C1 + 잔차 머리 FA → 16 → 1)·손실·소프트 층·사슬·표본 규율·고정값·판정 기준은 **v1 과 같다**(아래 §고정 — 글자 그대로 옮긴다).
바뀌는 것은 "조기 종료가 고른 머리를 쓸까 말까" 의 규칙(`Accept`)뿐이다.

| | v1 | **v2** | 왜 |
|---|---|---|---|
| 조기 종료·채택 지표 | 하드 규칙 포트 내부 검증 **연수익** 차이 | 같은 장부의 **일수익 차이(머리 − h 0)의 t 값** | 척도가 없다 — 창 길이·변동성·시장이 달라도 같은 자. 연수익 여백은 가장 짧은(가장 시끄러운) 창이 정해 긴 창을 통째로 막는다(아래) |

| 내부 검증 창 | 학습창 마지막 20% | **같다(20%)** | (b) 40% 는 아래 — 채택하지 않았다 |
| 합성 섞기 점검 | 여백 0 으로(누설 점검만) | **실자료 여백을 건 채로** \|D1a − C1\| ≤ 2%p | 거짓 채택 억제를 판정 전에 확인한다 |

- **t 값** = 내부 검증 결정일부터 하드 규칙 장부(D1a = kit 규칙 포트와 일수익이 같은 이 파일의 장부 · D1b = 기울이기 장부)를 머리 점수와 h = 0 점수로
  각각 굴려, 시장별 일수익 차이를 한 줄로 이어 평균 / (표준편차 / √n). 에포크 0(h = 0)은 t = 0. 이득 = 최고 에포크의 t(≥ 0). 조기 종료도 같은 t 로(인내 3).
  보유가 10세션 이어져 일수익 차이에 계열상관이 남는다 — 그래서 t 는 "유의성" 이 아니라 **자**이고, 문턱은 이론값(1.645)이 아니라 실자료 섞기로 굽는다.
- **합동 결정의 절차**(`walk_pooled`): ① 시드마다 학습만(판정 예측 없음 — 머리는 `-heads.pkl` 조각으로 남긴다) ② 재학습 j 마다 시드 평균 이득 > 여백 → 채택
  ③ 결정대로 ①의 머리를 얹어 예측(다시 학습하지 않는다 — 테스트가 "전부 채택이면 머리마다 채택한 walk 와 예측이 같다" 를 단언). 학습 비용은 v1 과 같다.
- **여백** = 실자료 라벨 섞기(`shuffle --track v2 --i-registered`, v1 과 같은 절차 — 학습 라벨을 세션 안에서 섞고 판정과 같은 재학습, 내부 검증은
  진짜 수익, 판정 블록 예측 없음)의 이득 t 값을 재학습별로 시드 평균한 7개(변형마다)의 최댓값. 파일 `data/_diag/final-round/D1/shuffle-margin-v2.json` 에
  등록 해시 · 백본 · 시드 · **채택 규칙**(지표·창·분위·합동)을 같이 적고, 판정·canary·합성 섞기는 읽기만 한다(없거나 어긋나면 rc 7).

## 자기 점검 (판정 전 — 러너가 셋 다 통과해야 판정을 시작한다)

1. 실자료 `shuffle --track v2 --i-registered` — 여백을 얼린다(판정 블록 수익 안 봄).
2. 합성 `canary --track v2 --i-registered` — 그 여백을 건 채로 **D1a − C1 ≥ 1%p**(⑥의 문턱). 못 넘으면 rc 7(여백이 신호를 막는다).
3. 합성 `shuffle --synthetic --track v2 --i-registered` — 그 여백을 건 채로 **|D1a − C1| ≤ 2%p**(①의 문턱). 넘으면 rc 7(거짓 채택).

합성 점검은 등록 값 그대로(첫 판정 블록만 합성 창 길이에 맞춰 6), 시드 5. 둘 중 하나라도 불통과면 **판정하지 않고 멈춘다** — v2 를 또 고치려면
새 등록(v3)이고 시행 수를 또 센다.

## 대조와 판정 — v1 과 같다

대조군은 kit 캐시를 읽기만 한다(`require_controls`, rc 3), 모두 D1 첫 판정 블록부터로 잘라 잰다.
D1a: `kit.judge(D1a, C0, C1)` · D1b: `kit.judge(D1b, T0, T1)`(같은 기울이기 장부) + v2 기준.

### 채택 기준 — 변형마다 (v1 과 글자 그대로)

① 시드 평균 연수익 ≥ 대조0 + 2%p ② 시드의 80% 이상이 대조0 보다 높다 ③ 두 국면(박스 ~2024-12 · 급등 2025-01~) 모두 ≥ 대조0 − 1%p
④ ΔIC(h5) ≥ 0 ⑤ MDD 가 2%p 넘게 깊지 않고 회전 ≤ 대조0 × 1.2. **DFL 주장**은 ⑥ ≥ 대조1 + 1%p.
(대조0·대조1 = D1a 는 C0·C1, D1b 는 T0·T1.) ⑥ 없이 ①~⑤ 만이면 "정보가 늘어서" 이고 대조1 을 채택 후보로 적는다.

**D1b 는 v2 기준을 더한다**: ⑦ 지수 대비 IR ≥ 0.30 ⑧ 두 국면 지수 대비 초과 ≥ 0 ⑨ 신호 없는 같은 구성 B0(λ = 0) 대비 연수익 ≥ 0. ①~⑨ 모두면 채택.

채택은 **후보**일 뿐 — **11/23 금고(2026-07-01~11-13)** 에서 얼린 머리로 한 번 더(규율 16). 성향 점검(규율 15 — β·박스/급등 β·가치·배당 노출 대 백본)은
v1 과 같이 채택 전 필수 기록.

## 다중검정 기록

- **family `selection` 시행 수 +1**(D1a·D1b v2 각 1회 판정). v1 은 판정 전 멈춰 research_trials 판정 기록이 없지만, 같은 가설(DFL 이 C1 보다 낫다)의
  두 번째 설계이므로 **재시도로 센다** — 기록 이름 `decision-focused-v2-2026-10:{D1a,D1b}-C1`, 판정 줄에 "v1 rc 7 뒤 재설계" 를 적는다.
- v2 가 바꾼 규칙은 **판정 블록 수익을 보지 않고** 골랐다 — 근거는 실자료 섞기(학습창 안 내부 검증만)와 합성 자료뿐이다.
- 이 판정 창은 수십 번 쓴 창이다 — 채택돼도 금고 심사 전에는 실전에 넣지 않는다.

## 한계

- v1 §한계 그대로(판정 창 재사용, 31블록·박스 259세션, 소프트 상위-k 그래디언트는 경계 근처만, 머리가 작아 C1 에서 멀리 못 간다).
- t 값은 일수익 차이의 두꺼운 꼬리·국면 변동에 둔감하지 않다 — 실자료 여백이 그만큼 커진다. 그래서 여백은 여전히 실자료로 굽는다(이론값 1.645 를 쓰지 않는다).
- canary 는 D1a 만 점검한다(선정 층). D1b 의 여백은 실자료 섞기로만 정해진다 — v1 과 같다.
- 합성 비교의 t 여백(0.80)은 합성으로 구웠다. 실자료 t 여백이 **1.30 을 넘으면** canary 의 첫 재학습이, **1.75 를 넘으면** 둘 다 기각되어 canary 가
  v2 에서도 막힌다 — 그러면 rc 7 로 멈추고 판정하지 않는다(그것이 이 점검의 목적이다). 그때는 v3 가 아니라 "이 자료·이 창으로는 DFL 의 몫을 가를 수 없다" 로 적는다.
- 합동 결정은 재학습 단위로 켜고 끈다 — 한 재학습 안에서 시드 사이 흩어짐(①②)은 그대로 판정 기준이 본다.
