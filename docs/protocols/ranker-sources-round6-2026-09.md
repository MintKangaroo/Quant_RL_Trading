# 사전등록 초안 — 6차 학습: 랭커 정보원 추가, "무너질 종목" 피처 4묶음 (2026-09-06 초안 · family `ranker` · 묶음당 1회)

측정 전에 고정한다. 결과를 보고 기준을 바꾸지 않는다 (self-improvement.md §1②).
**측정 시점: 2026-10-01 이후**(2026Q3 예산 181/200 소진, 집행 RL 2차와 같은 분기). 그 전엔 판정 구간의 어떤 수치도
계산하지 않는다 — 피처 **커버리지**(행 수·결측 비율)만 미리 본다(`tools/ranker_source_features.py --coverage`).

## 왜 이것인가

- 매매 전반 DRL 은 기본값에서 뺐다(`docs/rl-postmortem.md` §10, 재개 조건 있음). 지금 남은 학습은 **지도학습 랭커의 입력을 넓히는 것**뿐이다.
- 2026-08-31~09-01 시행 A·C·D·G 는 전부 "fundamental 위 한계기여 0" 에서 기각됐다. 그때 대조는 가중합이었고 신호 부호를
  손으로 정했다. 지금 대조는 **순위 목적 GBM(시행 L)** 이다 — 부호·비선형은 모델이 배우므로, 같은 재료라도 "랭커 위 한계기여"
  는 다른 질문이다. 다만 A·C·D·G 재료 자체는 여기 다시 넣지 않는다(같은 분기 재시도 금지).
- 2c(`alpha-decay-breadth-2026-09.md`)의 발견: **알파의 대부분이 하위 십분위(무너질 종목)에 있다**(두 시장 다 −80~−160% 연환산).
  랭커가 잘하는 것은 "무엇을 살까" 보다 "무엇을 피할까" 다. 그러니 다음 정보원은 상승 예측이 아니라 **붕괴 예측** 재료여야 한다:
  유동성 고갈 · 부실/희석 공시 · 공매도 흐름 · 내부자 처분.
- 랭커 gain 은 risk 51%(저변동·유동성·저베타)다. 유동성은 이미 `liquidity`(log 거래대금 수준)로 들어가 있다 — 여기서 넣는 것은
  **수준이 아니라 변화**(마르고 있는가)다. 수준을 다시 넣으면 시행 L 의 것을 복제한다.

## 공통 고정

- **모델·데이터·워크포워드는 시행 L 과 완전히 같다**(`rank-objective-ranker-2026-09.md` "고정" 절): LightGBM 잎 7 · min_data 2,000 ·
  lr 0.03 · 300 라운드 · bagging 0.8 · L2 1.0 · seed 0, 국장+미장 합침, 피처·타깃 세션×시장 안 rank-gauss(결측 0), 확장창 ≥150 ·
  20세션 예측 · 퍼지 5. 홀드아웃(2026-07-01~) 안 연다. 국장 판정 5블록 100세션, 미장 같은 날짜 블록.
- **대조 = 기본 7피처**(chart·event·flow·fundamental·regime·risk·is_us) 로 같은 루프에서 학습한 랭커. 실전 `ranker-v0.1.0` 을 쓰지 않는
  이유: 같은 루프·같은 시드 안에서 재현해야 차이가 피처 때문임을 말할 수 있다. 처리 = 기본 7피처 + 묶음 피처(전부 rank-gauss).
- **관측 시각 규칙**: 피처는 세션 s 에 대해 `observed_at` 이 **s 의 직전 세션 마감 이후 ~ s 개장 전** 까지 알 수 있었던 행만으로 만든다
  (국장 09:00 KST · 미장 09:30 ET). 창고 `observed_at` 을 그대로 쓴다 — DART/EDGAR 는 접수일 18:00, FINRA 일별 공매도는 익영업일
  공표 시각, 격주 잔고는 결제일+10영업일(시행 I 규칙). 시각을 하루라도 당기면 그 피처 전체가 무효다.
- 피처 값의 결측(자료 없음·창 미달)은 rank-gauss 뒤 0(중앙). **어느 시장에 없는 재료는 그 시장 전체가 0** 이 되고, GBM 은 `is_us`
  와의 교호로 이를 배운다 — 그래서 시장 한쪽 재료도 합쳐 학습한다(분리 학습은 시행 L 의 설정이 아니다).
- 묶음마다 피처 수 ≤ 3. 묶음 안 피처는 **한 번에** 넣고 뺀다(개별 피처 사후 선택 금지). 다중검정: 묶음 4개, 묶음마다 1회 판정.

## 채택 기준 — 묶음마다 넷 다 통과해야 채택 (시행 L 의 넷과 같은 형식, "주 시장" 만 묶음별로 다르다)

| | 기준 | 값 |
|---|---|---|
| ① | **주 시장** 판정 블록 ΔIC(h5) = 처리 − 대조, 일별 차이 NW t(lag 4) | ≥ 2.0 |
| ② | 주 시장 상위 24 동일가중 h5 z-수익 | 처리 ≥ 대조 |
| ③ | 주 시장 최악 20세션 블록 ΔIC | ≥ −0.03 |
| ④ | **다른 시장** 판정 블록 ΔIC(h5) | ≥ 0 (지지 않을 것) |

주 시장: G1·G2 = **국장**(①②③) + 미장(④). G3 = **미장**(①②③) + 국장(④). G4 = **국장** + 미장(④).
함께 적되 기준 아님: 하위 십분위 h5 z-수익(처리 ≤ 대조 인지 — 2c 의 가설 확인용), 피처 gain, 시장별 IC, 상위 80 z-수익(시행 S 가
채택되면 그것이 실전 폭이다). 기준 아닌 것이 기준을 뒤집지 않는다.

**묶음이 채택되면** 다음 묶음의 대조는 **채택된 피처를 포함한** 랭커다(누적). 기각이면 대조는 그대로.
넷 중 하나라도 실패 → 그 묶음 기각, 이 분기엔 다시 안 연다. 표본 미달(주 시장 판정 세션 < 100)은 기각이 아니라 **보류**(시행 미소진).

## 묶음 (순서 고정 — 자료가 완전한 것부터)

### G1 — 유동성 고갈 (prices 만 · 두 시장 · 전 기간)
| 피처 | 정의 | 뜻 |
|---|---|---|
| `turnover_decay` | log(ADV20 / ADV120), ADV = 거래대금 평균(`value`; 미장은 LS `amount`) | 최근 거래가 말라가는가 |

## 채택 시 배선 (측정 뒤 별도 커밋)

1. `analysts/ranker.py` 의 `FEATURES` 에 묶음 피처 추가 → `ranker-v0.2.0`. 피처 계산은 **`ranker.features()` 안에서 store.get 으로**
   (백테스트·라이브 같은 코드, 불변식 5). 시행 도구와 실전이 같은 함수를 쓰도록 계산 함수는 `quant_rl_trading/analysts/ranker_sources.py`
   에 두고 시행 도구가 그것을 import 한다.
2. `tools/train_ranker.py` 월말 모델 열 재학습 → 신호 백필(`backfill-ranker-signals`) → **IC 관문 재통과**(`measure_ic --analyst ranker`,
   국장·미장 둘 다 합격선 0.03) → shadow → 모의계좌. 관문을 못 넘으면 v0.1.0 으로 되돌린다.
3. 채택된 피처의 원자료 수집기가 죽으면 그 피처는 결측(0)이 되어 모델이 조용히 v0.1.0 근처로 퇴화한다 — `analyst_failures` 와
   데이터 품질 화면에 **피처 결측 비율**을 올린다(조용한 실패 금지).
