# 사전등록 — 매매 전반 RL 베타 (2026-09-02, 사용자 요청)

**회차를 세지 않는 베타다.** 학습 예산(`docs/design/self-improvement.md` 시행 예산)을 소진하지 않고,
채택돼도 배선은 **별도 사전등록** 뒤에만 한다. 다만 홀드아웃 봉인과 "측정 전 고정"은 그대로 지킨다 —
그게 없으면 베타의 결과도 못 믿는다.

## 왜 하나

지금까지 RL 에 준 일은 세 번 다 "규칙이 고른 24종목을 어떻게 나눌까"(M4 1~3회차)였다. 종목 선정·
사이징·회전을 **한 번에 포트폴리오 손익으로** 배우게 한 적은 없다. 안 될 것이라는 근거는 셋이지만
(같은 재료의 지도학습 랭커가 두 번 기각, 여지 지도의 정보 병목, 표본 1,250세션) 전부 추론이지
측정이 아니다. 이 시행이 그 측정이다.

## 데이터 (랭커 시행과 같은 발판 — 그래야 "랭커가 실패한 그 지점"을 잰다)

- 피처: `data/_diag/features-{chart,event,flow_kr,fundamental,regime,risk,volume}-KR.pkl` 의 **34개 전부**
  (KR 300세션, 2025-05-21~2026-08-11). 세션별 횡단면 z, 결측은 0(중립). 유니버스 `tradable-KR.pkl`.
- 수익: 창고 수정 종가(`store.prices.read_prices(adjusted=True)`). 진입 지연 1일 —
  세션 t 의 결정은 t+1 종가에 들어가 t+2 종가에 평가된다(타깃 pkl 과 같은 규약).
  일수익 ±50% 초과는 결측 처리(여지 지도의 MAX_MOVE 와 같은 이유 — 데이터 사고가 표를 지배한다).
- 판정 세션은 **2026-06-30 이전만.** 홀드아웃(2026-07-01~)은 열지 않는다.
- IC 판정 타깃: `targets-KR-h5.pkl` (랭커 시행과 동일).

## 상태·행동·보상 (고정)

- **상태** (종목별): 34피처 z + 현재 보유비중 1 = 35. 종목 축 공유 MLP(35→64→64, ReLU) 뒤에
  횡단면 평균 풀링 64 를 이어 붙여(128→64→1) 점수 하나. 종목 순서에 불변, 종목 수에 무관.
- **행동**: 점수 softmax → 유니버스 전체의 롱온리 비중(합 1). 온도는 학습하지 않는다(점수 크기가 그 역할).
- **보상** (세션마다): `w_t·r_{t+1} − 0.0041·‖w_t − w̃_{t−1}‖₁ − r̄_{t+1}`
  — 정책 비중의 다음날 수익, 편도 0.41% 회전 비용(선정 시행 3·시행 A 와 같은 값), 유니버스 동일가중 대비.
  w̃ 는 하루 드리프트한 직전 비중. 낙폭 벌점(`config.reward`)은 이 베타엔 넣지 않는다 — 넣으면
  "선정이 배웠나"와 "낙폭을 피했나"가 섞인다.
- **에피소드**: 학습창 전체 하나. 연속 시뮬레이션, 비중은 매 세션 다시 낸다.

## 학습 (고정)

시뮬레이터가 미분가능하므로 **에피소드 누적 보상을 정책 파라미터로 직접 미분**해 오른다 — 분산 0 의
정책경사다. PPO 는 같은 그래디언트를 표본으로 추정하는 것이라 여기서 지면 PPO 는 더 못 한다.
반대로 여기서 이기면 그때 PPO(확률 정책·낙폭 벌점 포함)를 별도 등록한다.
Adam lr 1e-3 · weight decay 1e-4 · 200 스텝 · 그래디언트 클립 1.0 · 시드 0·1·2 를 따로 학습해
**점수 평균(앙상블)** 을 판정에 쓴다 — 시드 하나면 초기화 운을 판정한다.

## 워크포워드 (랭커 변형 B 와 동일)

확장창: 최소 150세션에서 시작, 다음 20세션 예측, 20세션 전진, 퍼지 5. 예측 세션 합집합이 판정 표본.
대조군은 같은 세션의 `fundamental` 점수(현행).

## 채택 기준 (랭커 시행과 동일 — 바꾸지 않는다)

1. ΔIC(h5) = IC(정책 점수) − IC(fundamental) 일별 차이의 NW t ≥ 2.0
2. 상위 24 동일가중 h5 평균 초과수익 ≥ 대조
3. 어느 20세션 블록도 정책 IC 가 대조보다 0.03 이상 낮지 않을 것

셋 다 통과 → "채택 후보"로 적고 배선 사전등록으로 넘어간다. 아니면 기록만 남긴다.
함께 적되 기준이 아닌 것: 정책 비중 그대로의 순초과수익·연회전·유효종목수(1/Σw²), 학습창 내 보상.
"학습창에서 오르고 예측 블록에서 0" 이면 그건 랭커와 같은 실패(외움)이고 그렇게 적는다.

## 결과 (2026-09-02, 사전등록 해시 5724d33dafcae414, 커밋 e282430) — **기각(기록만)**

판정 100세션(5블록, 2026-01-08~2026-06-08). 종목 2,872 × 피처 34, 시드 3 앙상블.

```
정책 IC(h5) +0.0428 (t 1.23)  대  fundamental +0.0809 (t 4.78)
1. ΔIC −0.0381 · NW t −1.03                      미달 (기준 ≥ 2.0)
2. 상위24 h5 z-수익 정책 +0.1475 대 대조 +0.0183  통과
3. 블록별 ΔIC +0.038 −0.025 −0.062 +0.045 −0.186   미달 (최악 −0.186, 기준 ≥ −0.03)
학습창 누적초과: 시작 −0.02 → 끝 +3.6 ~ +6.8 (블록 1→5)
정책 비중 그대로(시드 2, 판정 100세션): 순초과 연 +2.38 · 비용 전 +2.90 · 일회전 0.50 · 유효종목 1
```

**읽는 법.**
- **외웠다.** 학습창 안에서 누적초과 +360~680% 는 softmax 가 종목 하나로 무너져(유효종목 1) 매일
  그날의 승자를 집어낸 결과다. 랭커와 같은 실패 양식이고, 정도는 더 심하다 — 랭커는 20세션 뒤 IC 0
  이었고 이 정책은 학습창에서 오라클에 가깝다.
- 예측 블록의 IC 는 fundamental 의 절반이고 블록 간 편차가 크다(−0.186 ~ +0.045). 2번 기준(상위24
  z-수익)은 통과했지만, **3스텝짜리 배관 확인(거의 초기화 상태)에서도 +0.115 였다** — 이 지표는
  꼬리 몇 개가 지배하는 잡음이지 학습의 증거가 아니다.
- 정책 비중 그대로의 순초과 연 +238% 는 종목 하나에 매일 절반을 갈아타는 궤적이다. 국장 상한가
  연속(단기 모멘텀·거래량 급증) 을 잡았을 가능성이 크지만, 편도 0.41% 비용 모형은 그런 종목에서
  거짓이다 — 상한가 잔량은 체결이 안 된다. 집행 가능한 알파로 볼 수 없다.

**결론.** 같은 재료로 선정·사이징·회전을 한 번에 배우게 해도 fundamental 을 못 이긴다. 원인은
랭커 변형 B 의 결론과 같다 — 이 표본에서 데이터로 가중을 배우는 것 자체가 사전 부호보다 못하다.
"매매 전반 RL" 은 이것으로 측정됐고, 다시 하려면 (a) 표본 2배 이상 또는 (b) 낮은 회전을 강제하는
제약(유효종목 하한·회전 상한) 을 가설로 둔 **새 등록**이어야 한다. 회차는 소진하지 않았다.
