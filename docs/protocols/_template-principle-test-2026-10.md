> 이 파일은 **등록 문서가 아니다**(해시를 고정하지 않는다). 랭커·재료·모델을 바꾸는 새 등록(C1G·TK·새 정보원 …)이 기준 절을 이 틀로 쓴다.

## 0. 등록 전에 반드시 채우는 것

| 칸 | 내용 |
|---|---|
| 처리 · 대조 | 처리 점수 / **신호 없는 같은 구성**의 대조 점수(복기 규칙 ⑨) — 같은 시드·같은 포트 규칙 |
| 판정 창 | 금고 창 이름·세션 수(예: second 30세션). 판정 가능일 = 창 끝 h5 라벨이 닫힌 뒤 |
| 우주 | **실전과 같은 거래가능 유니버스**(그 세션 공표 as_of 의 `Analyst.tradable_entities` — 유동성 하한·가격·유형 현행 규칙) 전 종목 |
| 기대 효과 δ | 탐색 결과의 **절반 이하**(선택 편향 — 결과를 보고 고른 시행이면 더 깎는다). 어디서 얼마였는지 적는다 |
| 검정력 표 | 금고 밖 자료로 판정 창 길이 블록의 ΔIC 분포 → 문턱별 1종 오류·δ 에서의 검정력(아래 2) |
| 오염 기록 | 무엇을 보고 이 시행을 만들었나, 판정 창 자료를 본 적이 있나 |

## 1. 주 기준 — 원리 시험(종목 × 세션, 짝 비교)

세션 t 마다 거래가능 전 종목에서 **h5 순위 IC**(Spearman, 처리 점수 대 t+1→t+6 수익)를 처리·대조 각각 재고 **ΔIC_t = IC처리 − IC대조**.
시드 s 마다 ΔIC_{s,t}, 판정 숫자는 시드 평균 ΔIC_t.

| | 기준 | 비고 |
|---|---|---|
| P1 | 창 평균 ΔIC > 0 **그리고** NW t(lag 4) ≥ **t\*** | t\* 는 검정력 표에서 정한다(1종 오류 ≤ 10% · δ 에서 검정력 보고) |
| P2 | 시드 일관 — 시드별 창 평균 ΔIC_s > 0 인 시드 ≥ **k**(5 중) | k 도 표에서(귀무에서 우연히 넘는 비율을 적는다) |
| P3(보조, 해 방지) | 십분위 스프레드 짝 차(D10−D1, 타깃 백분위) 창 평균 ≥ −(블록 표준편차 × 1.645) | 주장 아님 — "순위의 꼬리가 무너지지 않았나". 그 알파가 사는 자리(상위·하위 분위)가 따로 있으면 그 분위로 |

**규칙**: 문턱은 **금고 밖 자료**(금고 전 판정 창 + 이미 강등된 금고 창)에서 정한다. 같은 창으로 문턱과 판정을 함께 하지 않는다.
검정력이 모자라면(δ 에서 80% 미만) 그 사실을 등록 문서 첫머리에 적고 **전방 순차 검정을 병행**한다(아래 4).

## 2. 검정력 계산 (등록 전 의무)

`tools/power_principle.py --case <이름> --block <창 세션 수>` 와 같은 방식:
1. 금고 밖 일별 ΔIC_t(시드 평균) 계열을 만든다 — 처리·대조 모두 **OOS 예측**(워크포워드 또는 학습 끝 뒤).
2. 귀무 = 계열에서 전체 평균을 뺀 것. 대립 = 거기에 δ 를 더한 것.
3. 판정 창 길이 블록(5세션씩 밀며)마다 NW t. 표: 문턱(1.0·1.28·1.645·2.0)별 **귀무 통과율(1종 오류)** 과 **δ 별 통과율(검정력)**.
4. 시드 일관 k 도 같은 블록에서 귀무·대립 통과율.
5. 최소 탐지 효과 ≈ 2.80 × (블록 평균 ΔIC 의 표준편차) 를 같이 적는다.

## 3. 포트 — 해 방지만 (이 셋으로 "이겼다" 를 주장하지 않는다)

상위 N 포트(현행 구성 — EMA5 · 상위 24 · 완충 3N · 10세션 · 편도 0.41%)의 처리 − 대조, 시드 평균:

| | 기준 | 여유의 출처 |
|---|---|---|
| H1 | 창 연수익 차 ≥ −1.645 × SE_ann | SE_ann = 금고 밖 판정 창 길이 블록의 연수익 차 표준편차 |
| H2 | MDD 차(처리 − 대조) ≥ −1.645 × SE_mdd | 같은 방식(블록 MDD 차 표준편차) |
| H3 | 연 회전 ≤ 대조 × (1 + 여유) | 여유 = 금고 밖 블록의 회전 비 분포 상위 95% − 1(구조적 차이를 담는다 — 금고 밖 평균 비를 같이 적는다) |

여유는 "운으로도 이 정도는 나쁠 수 있다" 의 한쪽 5% 다. 그보다 나쁘면 원리가 맞아도 **포트에서 해가 난다**고 보고 기각한다.

## 4. 전방 순차 검정 병행 (§10 ④ — 검정력이 모자랄 때 필수)

- shadow 장부 짝(처리 장부 − 대조 장부, 같은 실전 구성)의 일 초과수익에 asymptotic confidence sequence(`quant_rl_trading/modelops/sequential.py`).
- 하한 > 0 "우세 확정" · 상한 < 0 "열위 확정" · 그 사이 "모름". 매일 봐도 1종 오류가 커지지 않는다.
- 짝 장부의 일별 ΔIC 를 같은 식으로 따라가는 줄도 둔다(원리 시험의 전방판).
- 금고 판정과 별개의 **기록**이다 — 금고 기준을 바꾸지 않는다. 승격 결정은 둘을 함께 보고 사용자가 한다.

## 5. 판정 문구

- P1·P2 통과 + H1·H2·H3 통과 → **채택 후보**(실전 반영은 사용자 재승인).
- P1 또는 P2 미통과 → 기각(원리가 안 보였다). H 하나라도 미통과 → 기각(포트에서 해).
- 지표가 비거나 nan → 판정 불가(멈춘다, 조용히 기각하지 않는다).
