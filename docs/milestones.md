# 마일스톤

원칙: **M3까지는 RL 없이 돌아가야 한다.**
RL이 없으면 아무것도 안 되는 구조로 만들지 않는다. RL은 작동하는 시스템 위에 얹는 것이다.

각 마일스톤의 완료 기준이 전부 켜지기 전에는 다음으로 넘어가지 않는다.

---

## M1 — 데이터 창고 + 리플레이 엔진

에이전트 0명. 돈도 벌지 않는다.
**"과거 어느 시점이든 그때 알던 것만 정확히 재현"** 되는 상태를 만든다.

### 산출물
- `store/` — 이중시간 저장, 데이터 게이트
- `replay/` — Clock, 이벤트 로그, 체결 시뮬레이터
- `collectors/` — 시장 수집자, 문서 수집자
- Data Quality 화면
- `tests/invariants/` — 검증 테스트 4종

### 완료 기준
- [x] 과거 5년치 전종목 curated 백필 완료 (상장폐지 종목 포함)
- [x] 임의 과거 날짜 100개 리플레이 → 전부 결정론적
- [x] 결정론 / 미래 훔쳐보기 / 생존편향 / 정정공시 테스트 통과
- [x] `datetime.now()` 직접 호출 0건, 데이터 직접 조회 0건 (CI 검사)
- [x] 지연 실측 수집 시작 (p50/p90 대시보드 표시)

검증: `uv run python tools/verify_m1.py` — 다섯 항목을 실제 창고 위에서 확인하고
하나라도 실패하면 종료코드가 0이 아니다. 체크박스를 손으로 켜지 않는다.

2026-08-11 결과: KR 1,223 거래일 / 3,383,617행 / 커버리지 100% / 상장폐지 348종목,
리플레이 100일 바이트 일치(불일치 0), 수집 지연 p50 84ms · p90 1,069ms.

## M2 — Analyst 투입 + IC 검증

### 산출물
- `analysts/` — chart, flow_kr, flow_us, fundamental, news, sns, regime, event, risk
- `schemas/` — Signal, Verdict
- IC 측정 파이프라인 (purged K-fold + embargo)
- Agent Health 화면

### 완료 기준
- [ ] 9개 Analyst 전부 구현, Signal 기록 중
- [ ] 최소 2개 Analyst가 IC 0.03 통과 (OOS, 표본 200거래일 이상)
- [ ] 국장/미장 IC 별도 측정 완료
- [ ] News·SNS 거부 성적표 집계 시작
- [ ] 통과하지 못한 Analyst는 가중치 0(관찰 모드)으로 동작

> 백테스트 IC가 0.15처럼 나오면 재능이 아니라 버그다. 먼저 누수를 의심할 것.

## M3 — Selector + Executor (RL 없이 실전 가능)

**여기서 이미 돈을 벌 수 있어야 한다.**

### 산출물
- `selector/` — 후보 선정, Analyst 가중치 진화
- `executor/` — 주문 변환, 상한, 리스크 가드, 킬스위치
- Allocator 자리에는 룰 기반 베이스라인 (동일가중 또는 스코어 비례)
- Fund 화면, Decision Trace 화면

### 완료 기준
- [ ] shadow 10거래일 무사고
- [ ] OOS 백테스트 MDD 20% 이내
- [ ] 킬스위치 실제 발동 테스트 통과
- [ ] 실전 소액 투입 (배선 검증 목적)
- [ ] 슬리피지 실측이 모델 예측의 ±30% 이내

## M4 — Allocator 투입

### 산출물
- `allocator/` — 상태 인코더(set encoder), 정책, 학습 루프
- 보상 함수 구현 (`reward-and-risk.md` 그대로)
- Model Lab 화면

### 완료 기준
- [ ] explained_variance가 유의미하게 0에서 벗어남
- [ ] **액션 반영률 30% 이상** — 미만이면 RL이 아니라 룰 시스템이다
- [ ] 실현 비중 되먹임 동작 확인
- [ ] 룰 베이스라인 대비 shadow IR 우위
- [ ] shadow 20거래일 + 사람 승인 후 실전 승격

> M4에서 학습이 안 되면 재정식화를 반복하지 않는다.
> 3회 시도 후에도 explained_variance가 0 근처면 **M3 룰 베이스라인으로 되돌리고**
> 원인을 분리해 다시 접근한다. 선행 프로젝트는 9차까지 끌고 가다 폐기했다.

- [ ] Analyst별 성과 귀속이 가중치 진화에 피드백
- [ ] LLM 월 비용이 예산 내

## 중단 기준

각 마일스톤에 시한을 둔다. 시한을 넘기면 접거나 방향을 바꾼다.

- M4에서 RL 재정식화 **3회 실패** → M3 룰 베이스라인 유지, RL은 별도 트랙으로 분리
- Analyst가 6개월간 하나도 IC 0.03을 못 넘김 → 피처·타깃 설계를 원점 재검토
- 실전 12개월간 shadow IR이 지속적으로 음수 → 프로젝트 종료 검토

선행 프로젝트가 실패한 결정적 이유 중 하나는 **중단 기준이 없었다는 것**이다.
